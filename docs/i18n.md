# 国际化开发规范

Navo 继续使用 i18next / react-i18next。语言与设置持久化值保持不变：首次默认英文，支持英文和简体中文。翻译 key 与显示文案解耦，修改文案不需要修改业务代码或数据库。

## 资源组织

- `src/shared/locales.ts`：语言注册表、语言类型、默认语言及非法值回退规则。设置页选项和主进程共用此入口。
- `src/i18n/locales/<locale>/<namespace>.json`：各语言独立的嵌套 JSON，不从中文 key 自动生成中文资源。
- `src/i18n/resources.ts`：显式装配全部语言资源，新增语言但未注册资源会产生类型错误。
- `src/i18n/config.ts`：共用初始化配置；渲染进程与原生菜单各自创建实例，主进程不依赖 React。
- `src/i18n/i18next.d.ts`：从英文资源推导合法 key，开启严格 key 检查。

命名空间按业务归属划分：

| 命名空间 | 范围 |
| --- | --- |
| `common` | 共用动作、字段、排序、显示和反馈 |
| `tasks` | 任务面板、详情及任务操作错误 |
| `taskCreate` | 创建任务、资源、分支及关联筛选 |
| `issues` | Issue / PR 列表、标签及状态 |
| `workspace` | 导航、标签页和拆分视图 |
| `settings` | 设置各子页、资源管理及相关错误 |
| `review` | diff 审查、Git 操作及评论 |
| `terminal` | 内嵌终端状态 |
| `nativeMenu` | Electron 原生菜单 |

## key 与调用

使用 `namespace:section.meaning`，以语义而非具体文案命名，例如 `taskCreate:filters.provider.any`。命名空间内使用嵌套对象，字段采用 camelCase；不要用中文句子、英文句子、序号或用户输入作为 key。相同文案只有语义一致时才复用，否则分别命名。

```tsx
const { t } = useTranslation(["taskCreate", "common"]);
t("taskCreate:filters.provider.any");
t("common:actions.confirm");
```

组件声明其使用的命名空间，调用时保留完整 key。服务层使用 `src/i18n/index.ts` 导出的类型安全 `t`，它跟随当前语言，不在模块初始化时缓存已翻译字符串。

动态文案表使用 `TranslationKey<"issues">` 等受限类型或字面量联合，不用 `string` 或强制断言绕过检查。任务标题、项目名、文件路径、分支名和服务商名称直接显示；已知错误码映射到固定 key，未知后端消息不传给 `t`。

## 插值、复数与日期

- 可变内容使用命名插值，例如 `t("tasks:actions.viewLabel", { title })`，不把文案拼成 key。
- 数量影响文案时传入数字 `count`，调用基础 key：`t("tasks:counts.tasks", { count })`。
- 英文数量资源使用 `tasks_one` / `tasks_other`；中文使用 `tasks_other`。新增语言按 `Intl.PluralRules(locale)` 的类别补齐复数形式，而非只假设单复数两类。
- 跨语言及同一 key 的各复数形式保持插值变量一致。JSON 资源的插值一致性由测试检查，key 合法性由 TypeScript 检查。
- 日期沿用 `formatDate` 和当前语言的 `Intl.DateTimeFormat`；日期型字符串按本地日期处理，无效值原样保留。

## 新增文案或语言

新增文案时，在对应命名空间的所有语言文件中补齐 key 和翻译，再更新调用。英文是类型与资源检查的基准；运行时保留英文回退，但不能用回退代替完整翻译。

新增语言：

1. 在语言注册表中添加 locale 标识及该语言的自称。
2. 新建对应资源目录，补齐全部命名空间、插值和该语言需要的复数形式，包括原生菜单。
3. 在资源装配文件中显式导入并登记。语言类型、设置选项和设置规范化自动从注册表取得，无需修改为新的二选一分支，也不需要数据库结构迁移。
4. 执行下述检查，并检查新语言下长文案的实际布局。本次仅统一可扩展结构，未新增语言，也未实现 RTL 布局。

```bash
npx tsc --noEmit
npm run lint
node --test --test-concurrency=1 scripts/*.test.mjs
git diff --check
```

国际化回归覆盖语言与资源目录一致性、语义 key、漏译、空翻译、插值一致性、复数类别、即时语言切换、HTML lang、日期、默认设置兼容、原生菜单和类型错误用例。交互回归同时验证关联筛选等界面切换语言后保持原有行为。
