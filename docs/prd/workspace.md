# 应用壳层与导航

[产品需求索引](../../PRD.md)

## 1. 页面范围

- 左侧提供 Tasks、Issue，底部提供设置；首次启动默认 Tasks。
- 不展示旧会话列表、会话栏折叠按钮、品牌标题或旧审查/终端顶部 tab。
- 后退、前进按一级模块访问历史工作；到达边界时禁用。后退后进入新模块会替换原有前进历史。
- 点击底部设置可调整偏好和管理本地资源，不要求配置外部 Agent hooks。

## 2. 顶部工作区标签

- 标签栏右侧固定提供创建任务图标按钮，打开[创建任务弹窗](task-create.md)。按钮保持可见且不属于窗口拖动区；创建完成进入 Tasks，不新增或激活真实任务标签。

- 顶部展示当前窗口中打开的真实任务标签，不再展示固定占位数据。首次启动标签栏为空；从任务侧栏的“打开任务页面”按钮或任务右键菜单的“以标签页打开”添加或激活对应任务标签，主区域展示任务页面，同时收起侧栏。
- 标签以任务标识去重，标题使用任务名称且不参与界面文案翻译。任务改名、状态和上下文更新后页面同步；任务删除后移除对应标签，关闭标签不删除任务、分支或 Worktree，不启动 Agent。
- 点击任务条目时，若已有标签直接激活对应页面，否则打开侧栏预览；看板、列表和右键“打开”遵循同一规则。
- 拖动时选中对应标签，选中状态跟随标签标识而非位置，相邻标签平滑让位。
- 关闭当前标签时，优先选中当前排列右侧相邻标签，无右侧标签时选左侧；关闭非当前标签不改变选中项。
- 允许全部关闭，关闭最后一个任务页后回到任务面板，不影响任务数据。标签顺序与选中仅在当前窗口内保留，重启不恢复。
- 点击 Tasks、Issue、设置或使用模块历史导航时返回相应一级页面，保留已打开标签；从任意模块点击任务标签进入该任务页。任务标签不单独写入模块前进/后退历史。
- 关闭按钮与标签选中、拖拽区域独立，不显示 tooltip，但保留无障碍名称。
- 标签右键菜单按独立页、组合页及当前选中状态展示拆分操作，保留“关闭”和“关闭其他”；重复右击时跟随最新鼠标位置，右击本身不触发拖拽或改变当前选中项。
- 菜单操作以右击的标签为目标。“关闭其他”以标签组为单位：独立页只保留自己，组合页保留两侧页面；仅剩一个标签组时禁用。不改变任务或 Issue 业务数据。

### 2.1 拆分入口与页面选择

- 没有激活任务标签，或右击当前激活的独立标签时，显示“拆分视图”。执行后左侧为右击的任务，右侧为“选择标签页”；此选择页不创建新任务。
- 激活独立标签 A 时右击另一个独立标签 B，显示“与当前标签拆分”，执行后直接组合为左 A、右 B。
- 选择页仅列出其他已打开且未参与任何拆分的任务。选择后把已有标签合并到组合中，原独立标签不重复保留；没有候选时显示空提示。取消拆分使用选择页右上角的 × 按钮，不展示底部文字按钮。
- 允许多个独立的双页组合，但一个任务最多属于一个组合，不允许嵌套或超过两个页面。

### 2.2 组合标签与布局

- 组合标签总宽 240px，左右各占一半，分别保留名称和关闭按钮，长标题省略。底色、圆角和轻量阴影沿用独立标签，不增加外侧描边，仅中间有分隔；点击任意半边激活整个组合并聚焦对应页面，不额外标记聚焦的半边。整组参与横向拖动排序，不把成员拖散。
- 默认并排显示，比例为 50% / 50%，两个独立圆角视图之间保留 8px 分隔条。可鼠标拖动或通过分隔条的方向键调整；并排时调整宽度、堆叠时调整高度。
- 调整分隔条接近均分点时吸附到 50% / 50%，不额外改变分隔线颜色，也不显示比例文字提示；吸入范围为 8px，吸附后拖离超过 16px 再恢复自由调整，避免临界点抖动。并排与堆叠均支持，保留普通悬停、拖动和键盘聚焦样式，不改变最小尺寸限制。
- 每个组合分别记忆并排与堆叠比例。视图有最小可用尺寸约束，小窗口收敛为均分，避免页面压扁。拖动即时反馈，布局切换有短过渡，尊重减少动态效果设置。
- 页面在拆分、交换、反转、取消拆分及一级导航切换中保持挂载，保留页面状态；任务数据始终共享。
- 点击任务条目时，如任务属于某个组合，则激活整个组合并聚焦该任务，不再次打开独立侧栏。

### 2.3 调整与关闭

- 无论右击组合的哪个成员，都显示“调整视图”子菜单，不再提供创建拆分入口。
- 子菜单包含：取消拆分视图、关闭左侧视图、关闭右侧视图、堆叠显示或并排显示、反转视图。堆叠时方向文案对应为上方、下方。
- 取消拆分保留两个页面，恢复为相邻独立标签，当前聚焦任务不变。反转交换页面及顶部成员顺序，比例不变，焦点仍跟随原任务。
- 点击任意半边的 × 或关闭对应视图，会关闭该页面并让剩余页面恢复独立显示；若组合当前激活，剩余页继续激活，关闭非当前组合不抢占正在查看的页面。
- 尚未选页时，关闭选择页即取消拆分；关闭原任务则一并移除临时选择页。反转及与空白侧交换在此阶段禁用。
- 删除任务时按关闭对应页面处理，组合自动收敛；所有页面关闭操作均不删除任务、分支或 Worktree。

### 2.4 独立标签与组合互换

- 当前激活的是拆分组合时，右击其他独立标签，显示“将标签页移至拆分视图”子菜单，包含“与左侧视图交换”“与右侧视图交换”；堆叠时对应显示上方、下方。
- 选择后，独立任务进入指定位置，原位置的任务回到该独立标签在顶部的原位置；其他半边不变，不新增、重复或关闭任何页面。
- 交换后激活换入的任务，保留组合标识、方向及比例。已经属于其他拆分组合的标签不能通过此入口交换，避免嵌套或拆散其他组合。
- 组合、比例和顺序仅在当前窗口内保留，重启不恢复。

## 3. 壳层布局

- 标题栏高 44px，空白区域可拖动窗口，后退与前进按钮属于不可拖动区。导航按钮高 28px、垂直居中，上下留白均为 8px。
- 前进后退右侧展示工作区标签，高 28px、字号 12px、圆角 8px，选中项使用主题主面板底色；标签过多时横向滚动，空白处仍可拖动窗口。标签支持横向拖拽交换位置，相邻标签平滑让位，松手后回到排列位置；尊重系统减少动态效果偏好。每个标签右侧提供 20px 关闭按钮，与选中及拖拽区域独立，不显示 tooltip，保留无障碍名称。任务页与面板共享数据，切换页面不触发工作区创建或销毁。
- macOS 原生红黄绿按钮定位为 x: 16px、y: 14px。
- 普通 macOS 窗口为原生红黄绿预留 88px，全屏或其他平台左侧内边距 12px。
- 左侧图标栏宽 56px，按钮 40px，图标 21px；Tasks、Issue 位于顶部，设置固定底部。
- 不显示会话栏折叠按钮、审查/终端顶栏 tab 或品牌标题。
- 页面主体右侧和底部均留 8px 壳层背景。

## 4. 独立详情与面板比例

- 未打开标签的任务及 Issue 条目点击后打开详情，左侧主面板和详情是两个独立圆角块，不是连续白色区域；任务已有标签时直接进入该任务页。
- 详情展示当前条目的标题与元信息，不自动打开 diff。
- 8px 间隔悬停显示左右调整光标，可拖动改变占用比例，并支持键盘左右键调整。
- 详情展开、收起和条目切换带过渡动画；系统减少动态效果时禁用位移动画。
- 点击关闭按钮收起详情，已选任务的详情随其状态变化同步更新。

- 背景为浅灰壳层；浅色主面板为白色，深色使用应用主题 token。
- 主面板和详情是独立的 14px 圆角块，不通过白色连续背景或分割线拼接。
- 未打开详情时主体铺满工作区；打开后显示独立右侧详情和 8px 灰色分隔条。
- 分隔条悬停显示 col-resize 光标和轻量提示线，可拖动或使用左右键调整比例。
- 主面板与详情接近等宽时使用相同的 50% / 50% 吸附和分隔线提示规则；均分比例按扣除 8px 分隔条后的可用空间计算。
- 默认详情约占可用空间 30%；通常左侧不少于 320px、右侧不少于 280px，小窗口按可用空间收敛。
- 拖动分隔条时宽度即时更新，不对鼠标跟随添加缓动；展开和收起保留约 240ms 动画。

同一窗口切换模块后保留详情选择和面板宽度。任务侧栏可提升为标签页，Issue 仍使用侧栏；均不自动打开代码审查或终端。

## 5. 验收标准

- 默认进入 Tasks，导航入口及可用历史准确，没有旧会话入口。
- 标签关闭、排序与相邻选中规则一致，允许空标签栏且不清空任务数据。
- 普通任务点击只打开侧栏，提升后展示真实页面；再次点击同一任务激活已有标签，不重复创建。任务改名、状态变化与删除同步到标签及页面。
- 右键菜单与激活状态匹配，选页排除所有已拆分成员；关闭其他保留完整目标组合，不能产生嵌套拆分。
- 左右／上下拖动、反转、取消、单侧关闭和删除任务均正确收敛；独立标签交换后原页面回到其原独立位置，任务与页面不丢失、不重复。
- 主面板和详情是两个独立块，中间间隔可见，支持鼠标及键盘调整宽度。
- 详情展开、收起和条目切换流畅；调整宽度时即时跟随，不附加缓动。
- 小窗口仍可访问主要内容；减少动态效果时不强制播放位移动画。
