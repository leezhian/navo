# 设置页面

[产品需求索引](../../../PRD.md)

## 1. 分类与入口

左侧底部设置入口打开设置工作区，默认常规。分类按以下顺序排列：
1. [常规](general.md)
2. [外观](appearance.md)
3. [Agents](agents.md)
4. [仓库与文件夹](resources.md)
5. [集成](integrations.md)
6. [关于](about.md)

搜索匹配当前语言下的分类名称；无匹配时显示提示。没有 Agent 监听或 hooks 配置入口。左侧全局导航保持可见，不使用整窗遮盖，也不重复提供返回应用按钮。

## 2. 页面结构

- 分类面板与内容面板是独立圆角块，中间间隔 8px；分类面板宽 208px，窄窗口收敛至 152px。
- 内容可独立滚动，最大宽度 760px；页面标题 18px，分区间距 24px；分类按钮高 32px、字号 12px。
- 设置项使用接近面板底色的 12px 圆角分组，无外层描边。左右内边距 16px、行上下内边距 16px，相邻行使用缩进分割线。
- 左侧名称 13px、说明 12px，右侧控件居右；内容宽度不超过 520px 时改为上下布局。
- 输入、选择器和常规操作按钮高 32px、字号 12px、圆角 8px。

## 3. 保存与升级规则

- 设置由桌面主进程保存到本地 SQLite；界面状态仅作为缓存，不另存第二份配置。
- 语言、外观、目录、任务偏好、诊断日志文件路径和已有 diff 阅读偏好即时生效，重启后恢复。
- 一次设置更新完整提交，写入失败保留上一份已保存设置；界面明确提示未保存并提供重试，不伪装为成功。
- 升级时优先读取已有 SQLite 设置。数据库尚无设置时，先迁移旧本地 JSON；成功后保留原文件作为备份，不再回读或覆盖它。
- 没有 SQLite 设置且不存在旧 JSON 时，才尝试更早版本的浏览器本地设置；写入成功后才清理旧浏览器配置。完全无历史配置时使用默认值。
- 迁移失败保留来源，允许修复后重试；数据库或历史配置损坏时展示错误，不以默认值或过时备份静默覆盖。
- 设置和任务共用本地 SQLite，任务关联与排序独立存表；资源目录、Issue、评论和历史审查数据仍保持原有存储边界。
- 新安装使用 Navo 用户目录，旧安装保留既有用户目录兼容规则。

## 4. 状态与验收

- 读取失败不展示假成功的空设置页；保存失败通过底部轻量错误条提供重试。
- 保存和文件操作期间禁用冲突操作，完成后状态准确恢复。
- 首次默认英文，切换语言即时生效且重启保留；用户输入的业务内容不被翻译。
- 六个分类、搜索和导航均可用，没有旧会话监听或关于页存储清理入口。
- 原有用户升级后外观、目录、语言等不丢失；失败不重置，重试可恢复。
- 设置更改后退出、重新打开仍可读回，整组更新不会仅保存部分字段。
