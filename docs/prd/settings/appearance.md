# 外观设置

[设置概览](README.md) · [产品需求索引](../../../PRD.md)

## 1. 视觉风格

- 分区名为“视觉风格”，不使用“界面”，标题下不展示“调整 Navo 的整体外观。”描述。
- 颜色模式提供跟随系统、浅色、深色，使用单选分段控件；选择后立即应用并保存。
- 分段控件使用浅灰底、主题面板色选中项与轻量阴影，遵循通用设计规范。

## 2. 代码差异

- 集中展示浅色代码主题、深色代码主题、代码字号和差异标记。
- 差异标记在颜色与 +/- 两种方式间切换；代码主题与字号只改变阅读呈现，不改变代码。
- 原有差异换行、统一/分栏、行内文字差异等审查偏好继续保存，具体操作入口见[代码审查](../review.md)。
- 分区底部保留带标题和示例文件名的实时 diff 预览，与当前主题及阅读设置同步。

## 3. 预览状态

- 首次打开也应展示示例代码；加载期间提供状态占位，失败提供重试，不持续停留在只有标题的空框。
- 切换主题或快速切换设置分类时，过期的加载结果不得覆盖当前选择。

## 4. 验收标准

- 系统、浅色、深色模式可正确切换，重启保持偏好。
- 修改浅/深色代码主题、字号与差异标记后预览即时更新。
- 首次进入、离开后重新进入、切换代码主题均能显示预览；异常可重试。
- 主题切换不重置任务、条目和审查上下文的选中状态。
