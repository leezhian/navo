# 常规设置

[设置概览](README.md) · [产品需求索引](../../../PRD.md)

## 1. 分区与功能

页面依次提供目录、任务、诊断日志、语言、快捷键，分区标题使用“任务”，不使用“任务默认值”。

1. 仓库目录默认 `~/Navo/repos`，Worktree 目录默认 `~/Navo/worktrees`，支持路径输入与系统目录选择。
2. 默认任务模式为隔离 Worktree，可选择新建分支或当前分支；分支前缀默认 `navo/`，允许留空。新任务中各仓库的初始执行模式取自此设置，可在任务草稿中逐个修改；设置本身不立即执行 Git 操作。目标分支留空时使用此处前缀加八位随机短 ID，前缀允许为空。
3. 保持唤醒开关仅保存偏好，描述其目标行为：Agent 会话启动、运行、等待输入或开启远程访问时阻止系统睡眠，屏幕仍可关闭。当前不实现 Agent 生命周期、远程访问或系统防休眠；仓库目录描述约定更改目录或显式扫描时才扫描，启动时不扫描，但目录扫描能力尚未接入。
4. 应用诊断日志始终记录到单文件，默认位于应用用户目录的 `logs/navo.log`。路径使用与仓库目录一致的输入框和目录选择按钮：可直接编辑完整文件路径，失焦或 Enter 时保存；也可选择所在目录并沿用当前日志文件名，不弹出保存文件对话框。支持在系统文件管理器中定位、复制路径和清理日志。修改位置后只将后续事件写入新文件，不移动或删除原文件；目标须为新建、空白或 Navo 格式的 `.log` 文件，防止覆盖其他内容。磁盘占用最高约 20 MB；超过上限时重置同一文件并继续记录，不产生额外轮转文件。无开关或保留时间设置；清理仅清空当前文件，提交错误报告时提示附上此文件。仅保存固定应用事件与时间，不记录对话、代码、认证凭证或终端内容，写入、路径修改和清理失败可见。
5. 英文与简体中文切换即时生效并持久化，首次启动默认英文；保留已有外观偏好。
6. 快捷键区仅列出已支持的操作，不提供自定义绑定；开发者工具快捷键仅在开发态展示。

## 2. 文案与目录交互

- Worktree 目录说明：Default directory for new worktrees。
- 仓库目录说明：Default directory for cloned repositories. Scanned when you change it here or scan explicitly — never on startup, so repositories you remove stay removed.
- 保持唤醒说明表达会话启动、运行、等待输入与远程访问开启期间阻止睡眠，屏幕仍可关闭；中英文含义一致，英文拼写和空格正常化。
- 分支前缀允许为空，但不展示“允许留空，不影响已有分支。”说明。
- 仓库与 Worktree 目录选择器默认打开当前用户主目录；取消时不修改原值。
- 任务模式、分支前缀及 Worktree 目录已用于任务创建；目录扫描、真实 Agent 生命周期和保持唤醒运行机制仍属后续范围。

## 3. 诊断日志布局与交互

- 说明为“磁盘占用最高约20 MB。提交错误报告时请附上此文件。”。
- 使用紧凑分组，圆角 12px，左右内边距 16px、上下 12px，不在左侧重复展示“日志文件”标题。
- 首行由等宽路径输入框铺满，右侧无底色的目录选择图标；输入完整文件路径可直接修改。
- 选择目录时从当前日志所在目录打开，沿用当前文件名，不调用保存文件对话框。
- 下方右对齐放置打开、复制路径、清理日志，间距 8px，按钮高 28px、字号 12px、图标 14px；窄窗口允许换行。
- 清理操作仅在悬浮时使用警示色，成功反馈显示在操作行左侧；保存和操作期间禁用冲突动作。
- 不提供日志开关、保留时间或日志目录单独配置；复制的是完整文件路径，打开操作在系统文件管理器中定位该文件。

## 4. 验收标准

- 默认路径、任务模式和分支前缀正确，修改后可持久化，选择目录取消不影响原值。
- 诊断日志始终为单文件，位置可修改，旧文件不被移动或删除；非 Navo 内容不得被覆盖。
- 打开、复制、清理日志均作用于当前设置的文件，清理不删除其他文件。
- 日志有约 20 MB 上限，无轮转或保留时间选项，不记录对话、代码、认证或终端内容。
- 语言切换后导航、说明和日期立即更新；快捷键只列出真实支持项，开发者工具快捷键仅用于开发态。
