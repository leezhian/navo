# 集成设置

[设置概览](README.md) · [产品需求索引](../../../PRD.md)

## 1. 功能范围

仅列出 GitLab、GitLab Self-Hosted、GitHub、GitHub Enterprise 和 Linear。当前所有状态明确为尚未连接的占位状态，连接按钮不可用；刷新仅重新加载本地占位数据，不表示远端授权或同步完成。

## 2. 展示与交互

- 沿用设置分组行，左侧显示对应平台的 20px 单色品牌图标，随后为名称与连接状态，右侧连接按钮禁用；图标适配浅深色主题，GitLab 自托管版与 GitHub 企业版共用各自平台图标。
- 页首明确标注占位状态，不展示虚构账号、权限或同步结果。
- 不包含 Agent 监听、hooks 注入或自动采集入口。

## 3. 验收标准

- 五个平台准确列出，全部明确显示尚未连接。
- 连接按钮不可用，刷新不触发授权或网络同步，不提示“已同步”。
