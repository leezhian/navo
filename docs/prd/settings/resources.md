# 仓库与文件夹

[设置概览](README.md) · [产品需求索引](../../../PRD.md)

## 1. 功能与边界

1. 添加仓库只需填写 HTTPS 或 SSH 地址，名称从地址自动提取，克隆到常规设置中的仓库目录，不提供名称或克隆位置输入；主操作为“确认”，不展示认证说明。使用系统 Git 现有认证，不保存密码或 token；展示脱敏进度并支持取消。
2. 资源列表只提供“添加仓库”入口，不单独展示“添加文件夹”按钮。可在添加仓库弹窗中选择或拖入已有目录，直接以目录名添加本地文件夹记录；系统目录选择器默认打开当前用户主目录，选中后添加，取消时不新增，不执行克隆；失败时展示错误。
3. 支持新增、编辑名称、本地路径、用途描述和命令配置、刷新可用性及确认移除记录。编辑弹窗只读展示当前目录的远程仓库地址，不修改 Git remote；移除不删除磁盘目录和文件。
4. 以规范化真实路径防止重复添加；克隆不覆盖已有目录，失败或取消只清理本次新建目标目录。克隆成功但记录保存失败时保留仓库并提示通过本地文件夹入口添加。
5. 路径失效、权限不足、Git 不可用、克隆失败及存储损坏应显示明确错误；不将失败伪装为成功或用空数据覆盖损坏记录。

## 2. 列表结构

- 页首保留“移除记录不会删除磁盘文件。”，不展示“记录本地资源供后续任务使用”。
- 只提供添加仓库入口和刷新操作，没有独立添加文件夹按钮。
- 资源行展示图标、名称、路径、命令数量、可用性与移除操作，整行点击进入编辑，不按固定单元格布局。命令数量独立放在条目右侧、移除按钮左侧，垂直居中并右对齐；没有配置命令时英文显示“No commands”，中文显示“暂无命令”，有配置时显示实际条数并支持英文单复数。编辑弹窗内仍不显示空命令占位。
- 首次加载和后续刷新均不显示“读取中”文字；仅通过刷新按钮转动提示，刷新期间保留已有列表或空状态，首次读取完成前不提前显示空状态。
- 文件夹由图标标识，不重复显示“文件夹”文字；仓库保留类型文字。路径不可用时明确提示。

## 3. 添加与编辑弹窗

- 使用应用组件库的对话框，依次排列标题、Git 地址输入、说明和本地目录拖入区。
- 说明位于 Git 输入框下方、拖拽区域上方：“粘贴仓库地址以克隆，或选择已有仓库的文件夹。”；英文为 Paste a URL to clone it, or pick a folder that already holds a repo。
- 不展示名称、克隆到或认证说明；主按钮为“确认”，取消不写入记录。
- 拖入区使用轻量虚线边框，提供选择本地文件夹按钮；选中或拖入目录后直接导入，失败留在弹窗展示错误。
- 文件系统条目拖入指定区域时，边框和底色轻量高亮，提示变为“松开以添加目录”；移出或松开后恢复。经过区域内文字和按钮时高亮保持稳定，禁用时不响应，目录有效性仍在松开后校验。
- 系统目录选择器默认用户主目录，例如 /Users/kim，不以克隆目标目录作为初始位置。
- 克隆中展示脱敏进度和取消入口，禁用冲突操作并防止误关闭。
- 点击仓库或文件夹条目打开编辑弹窗，不显示独立编辑图标；条目支持键盘访问和激活。移除按钮独立触发确认，不同时打开编辑；关闭编辑后焦点回到原入口。
- 编辑现有记录使用约 560px 宽的弹窗，正文限高滚动，保存和取消保持在底部。顶部以资源图标和可编辑名称作为主要信息，其下紧凑排列只读本地路径、复制及目录选择按钮、远程地址；以轻分割线与描述、命令区域分隔。名称不再重复展示字段标题或可见的“编辑资源”标题，也不展示修改路径的说明文案；不展示仓库级 Branch Prefix 设置。
- 名称默认以文本展示，点击后进入输入状态；回车或失焦确认草稿，Esc 取消本次名称修改，空名称保留原值。名称随弹窗保存统一持久化。本地路径不展示字段标题，以只读文本展示，只能通过文件系统按钮选择目录修改，旁边提供复制路径图标按钮。
- 远程地址从当前目录的实际 Git 配置读取，与记录被登记为仓库还是文件夹无关；优先 origin，否则使用首个 remote。不访问网络、不 fetch、不执行命令脚本，展示前移除 URL 中的密码、HTTP 认证信息和查询参数。无远端、非 Git 文件夹和读取失败分别展示对应状态，不拿克隆时保存的旧地址冒充当前 remote；修改目录后重新读取，旧请求不能覆盖新目录结果。
- 远程信息按目录使用内存缓存，不写入数据库。再次打开编辑弹窗立即展示上次结果，不清空地址或人为延迟查询；后台仅校验本地 Git 配置等相关文件的元信息，未变化时不再启动 Git 查询。修改目录、再次打开或窗口重新获得焦点时检查配置变化；列表手动刷新会强制更新已查询过的当前资源。刷新失败保留上次成功结果，首次查询失败才显示读取失败；同目录并发查询合并，应用重启后重新读取。
- 描述可留空，最多 4000 个字符；输入只更新弹窗草稿，点击保存后与名称、本地路径及命令一起持久化到资源记录。取消、关闭或 Esc 不保存修改。
- 命令列表支持添加、编辑和删除，显示名称、脚本摘要及“创建时运行”标记。命令表单在列表中展开，不叠加新弹窗；字段为名称、多行命令脚本、“创建 Worktree 时运行”复选框，复选框默认不勾选。名称和脚本不能为空，名称最多 100 个字符，脚本最多 20000 个字符，最多 50 条命令；脚本原样保存，不做执行或 Shell 展开。
- 未配置命令时只保留命令标题和添加入口，不显示空列表占位文案。
- 命令表单的确认只更新资源草稿，取消保留编辑前的命令；命令编辑尚未确认时禁用资源保存。编辑保留命令标识和列表顺序，删除命令也随父弹窗保存才生效。保存失败保留草稿，成功后再次打开回显全部配置。
- 设置页保存命令及自动运行标记，保存动作本身不执行脚本；任务工作台 CHANGES 的命令入口支持在指定工作区手动运行及停止，并可通过“管理命令…”打开同一个仓库编辑弹窗。仅在新 Worktree 创建并保存成功后，顺序执行勾选的命令；失败保留任务及目录，并在任务工作台提供重试，详见任务工作台的初始化规则。已有 Worktree 或普通目录不触发。旧资源缺少描述或命令时按空值读取，旧调用方未传这些字段时保留原配置。
- 主操作为保存；移除资源需确认且只删除记录。

## 4. 验收标准

- 添加仓库仅需地址，自动提取名称并使用常规设置的克隆目录。
- HTTPS、SSH 与 SCP 形式地址按既有校验处理，不保存密码或 token。
- 选择或拖入已有目录无需额外填写名称，取消不新增；真实路径重复时拒绝。
- 克隆失败、取消、Git/权限异常与持久化失败均有明确反馈。
- 成功克隆但记录失败时保留磁盘仓库，提示通过本地目录入口添加；移除记录不删除文件。
- 手动导入的 Git 仓库也能展示真实 remote，切换目录不残留旧地址；查看和编辑不会修改远程配置。
- 描述和命令支持中英文界面、持久化及旧记录兼容；取消不写入，失败不清空，勾选自动运行不会触发实际执行。
