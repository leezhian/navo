# 实验室

[设置概览](README.md) · [任务工作台](../task-workspace.md)

## 1. 范围

实验室管理需要单独安装的官方可选功能。首次使用和已有用户升级均不自动安装、启用或下载扩展。首个功能为「会话轨迹」，支持已绑定到 Navo 的 Claude Code、Codex 原生 JSONL 会话；暂不支持压缩归档、第三方扩展市场及全机历史扫描。

## 2. 展示

- 分类位于「集成」与「关于」之间，参与当前语言的设置搜索。
- 展示功能名称、说明、支持的 Agent、可安装版本、包大小、安装状态、启用开关、检查更新和卸载入口。有兼容新版时展示版本提示与「更新」按钮，检查中、上次成功检查时间及失败原因分别展示。
- 已安装与已启用分别表达；下载、更新及卸载进行时禁用冲突操作。读取失败提供重试，不用未安装空态冒充成功。
- 支持中文、英文和浅深色；窄窗口下操作换行，沿用通用设置风格。

## 3. 安装与生命周期

- 「安装」下载宿主内置或已验证官方清单中的兼容版本；「从安装包安装」由原生文件选择器选择，执行同样的来源完整性与兼容性校验。不能安装任意插件代码。
- 仅对已安装插件在应用启动约 30 秒后、此后每 4 小时后台检查一次更新；关闭插件仍可检查，未安装时不后台检查。可随时在实验室手动检查，重复检查合并，不自动下载或安装新版。
- 更新来源为官方签名清单，按宿主主版本和插件接口匹配，选择最新稳定兼容版本；只允许升级，不自动降级。签名失败、网络失败或没有兼容版本时明确提示，保留上次已验证的结果，不显示检查成功。
- 点击「更新」后下载并校验安装包，显示进度且可取消；更新期间暂时关闭轨迹入口，切换前停止插件进程。成功保留原启用偏好，失败恢复旧包与偏好；进程异常中断后在下次启动恢复未提交的更新。原生会话、终端和 Agent 不受影响，视图回退不触发 Agent 自动恢复。
- 首次安装的下载显示进度并支持取消。校验与保存成功后进入已安装、未启用状态，不自动打开轨迹。
- 发布源暂不可用、网络失败、包损坏、目录权限不足等情况显示明确原因。未发布的版本允许从经过同等校验的本地包安装，不伪装下载成功。
- 启用后为支持的会话提供轨迹入口，首次打开轨迹时才读取数据。不查看的会话没有轨迹解析进程或持续读取。
- 关闭立即移除入口、撤销访问、结束插件解析并释放视图订阅，保留安装包和可重建缓存。
- 卸载使用确认弹窗，默认焦点在取消，说明将删除插件、解析缓存及专属偏好。先关闭运行实例，再清理文件和安装记录；失败保留待清理状态并支持重试。
- 关闭和卸载不停止 Agent，不删除任务、原生历史、代码、仓库或 Worktree。
- 重启保留启用偏好，重新校验完整性和兼容性，按需加载。异常中断的安装先清理半成品；未完成卸载明确提示继续清理。宿主升级不兼容时禁止加载，可检查并更新到兼容版本或卸载重装。通过更新清单安装的版本保存签名凭证，内置基线版本按固定摘要校验；断网重启仍能校验并使用。

## 4. 数据边界

- 管理记录保存在本地；开发与正式环境隔离。解析插件独立分发，Navo 安装包不内置解析器或插件安装包；官方轨迹界面随 Navo 发版，未安装或未启用时不展示、不加载。
- 轨迹只读访问绑定的原生历史，不注入 hooks，不修改 CLI 全局配置，不上传会话数据。
- 缓存仅含可重建索引和解析结果，关闭停止更新，卸载清除。单会话索引有容量上限，总缓存按容量与最近使用情况淘汰，不无限增长。
- 插件异常不能影响原生终端或其他任务。诊断日志不包含轨迹正文、工具参数、代码或凭据。

## 5. 验收

- 默认未安装、未启用；安装后仍关闭，只有主动启用才出现入口。
- 下载、取消、校验失败、安装中断、启停、卸载失败与重试均有真实反馈。
- 多视图共享同一会话解析，最后一个视图不可见后停止读取；关闭插件释放所有读取和进程。
- 关闭或卸载后的自动回退不启动 Agent；原生文件和会话记录保持完整。
- 修改安装内容、更新清单签名无效、路径越界、不兼容版本或不匹配会话不能通过校验。
- 版本检查只读取清单；启用和关闭状态分别在更新成功、失败、取消、重启后保持。已提交更新不能因备份清理失败被误回滚，未提交更新不能留下半成品。
