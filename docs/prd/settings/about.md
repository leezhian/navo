# 关于

[设置概览](README.md) · [产品需求索引](../../../PRD.md)

## 1. 内容与操作

- 展示 Navo 名称与当前版本，不展示 ADE 产品描述。
- 版本和检查更新合并为一行，支持区域依次提供官网、报告 Bug 和诊断日志。
- 没有存储区域、缓存清理按钮或历史会话相关提示。
- 未接入更新服务时明确提示暂时无法检查，不宣称当前已是最新版。

## 2. 验收标准

- 名称、版本与实际应用一致，网站和 Bug 入口可打开。
- 更新检查反馈与实际接入状态一致，无假成功。
- 页面不提供通用磁盘存储或历史记录清理操作，清理日志仅作用于当前诊断日志文件。
- 常规页不再展示诊断日志；关于页不显示实际路径，但复制、定位和清理仍使用当前有效日志文件。
- 操作失败显示错误且可重试；清理成功显示轻量反馈，中英文界面和窄窗口均可操作。

## 3. 诊断日志

- 作为支持列表中的一行，位于问题反馈之后，与官网、反馈共用分组及分割线，不新增独立路径卡片。左侧为“诊断日志”和说明“磁盘占用最高约20 MB。提交错误报告时请附上此文件。”，字号分别为 13px 与 12px；右侧依次放置复制路径、打开、清理日志三个轻量按钮，按钮高 28px、字号 12px、图标 14px。窄窗口沿用设置项上下排列规则，操作按钮可换行。
- 不在正文、输入框或 tooltip 中展示实际文件路径，也不提供修改路径、目录选择、日志开关或保留时间设置。复制操作仍将完整路径写入剪贴板，打开操作在系统文件管理器中定位该文件。
- 日志默认位于应用用户目录的 `logs/navo.log`，历史已保存的自定义路径继续沿用，不搬迁或删除旧文件，不覆盖非 Navo 内容。始终记录到单文件，最高约 20 MB，超过上限重置同一文件并继续写入，不产生轮转文件。
- 清理仅清空当前文件，不删除其他文件。操作期间禁用冲突动作，错误和成功反馈位于操作组下方；清理按钮只在悬停时使用警示色。
- 日志是运行诊断而非全量操作审计。覆盖应用启停、设置读取/迁移/保存、资源增删改与克隆、任务操作、Worktree/本地分支创建及清理、回滚、数据库异常、附件处理，以及插件（轨迹打开、查询失败与解析进程异常退出）；服务商与 Agent 尚未接入时不记录占位事件。
- 每行包含时间、级别、模块、稳定事件标识和允许的诊断字段。耗时操作记录开始与结果及耗时，同次操作可关联；普通操作记录结果，高频成功读取不逐轮记录。不记录点击、输入和拖动过程。
- 只允许内部标识、数量、状态、变更字段名、错误码、退出码与脱敏堆栈等字段；设置字段值、任务标题/描述、代码/diff、对话、终端内容、Token、完整路径/URL、原始命令输出和任意请求正文均不进入日志。未知错误的原始消息不直接写入。
- 写入异步串行进行，不作为业务操作成功的前提；重复异常限频汇总，拥塞时限制队列并优先保留警告与错误。写入失败不改变任务或 Git 操作结果，可在日志设置中看到失败状态并重试相关文件操作。
- 主进程致命异常只尽力记录，保留默认退出行为；强制终止、系统掉电不能保证最后一条日志落盘。正常退出有界等待写入；渲染错误仅允许受限上报，不提供任意文件写入能力。
