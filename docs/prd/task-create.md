# 创建任务

[产品需求索引](../../PRD.md) · [Tasks](tasks.md) · [应用壳层](workspace.md)

## 1. 入口与边界

- 顶部标签栏右侧固定创建按钮打开弹窗，不改变已有任务标签的排序和关闭逻辑。创建任务本身不新增标签，后续可从侧栏提升为任务页。
- 创建本地 TODO 任务并按配置准备分支/工作区，不自动启动 Agent、选择模型、申请运行权限或连接远程平台。
- 所有参考图片仅用于说明功能，布局和控件遵循项目设计规范。

## 2. 创建弹窗

- 弹窗宽约 760px，适配窄窗口，正文可滚动，不设置独立底部操作区。
- 内容依次为上下文操作、组合输入区、工作目录。关联 Issue、关联 PR 按钮位于组合输入区顶部外侧，与输入区间距 8px，工作目录及添加入口紧邻底部外侧。不展示弹窗标题和说明文案，但保留辅助技术可识别的弹窗名称。“创建”按钮位于组合输入区内部底栏右侧，不展示取消按钮。通过右上角关闭按钮、Esc 或点击外部退出。
- 组合输入区共用一个外框，内部依次为关联回显、任务描述输入框、底部栏；底部栏左侧的附件图标打开菜单，包含“添加图片或文件”和“添加链接”，保留提示和可访问名称。回显支持换行、独立移除，条目较多时限高滚动；无条目时不占位。描述保持纯文本，移除回显不影响已输入内容。
- 文本输入框默认一行，随输入换行自动增高，最多展示 8 行；超出后仅文本区域内部滚动，删除内容后自动缩回，不提供手动拉伸。
- 描述必填；标题自动取去掉首尾空白后的首行，最多 80 字，可创建后重命名，不增加标题输入框。
- 关联条目、附件、普通链接和工作目录均可选。关闭弹窗保留当前窗口内草稿，成功创建后清空。
- 查询、选择文件和创建期间禁用冲突操作，创建期间防止误关闭，失败保留草稿并展示错误。
- 关联选择、工作目录选择和快捷添加以子弹窗逐层叠加，底层创建表单及目录选择器保持显示和挂载，不清空草稿或中途编辑内容。仅最上层可交互；Esc、点击遮罩或关闭按钮仅关闭当前层，返回后恢复父层入口焦点，不连带关闭创建流程。

## 3. Issue 与 PR

- 分别打开对应类别的选择弹窗，与 Issue 页共享完整数据，而非当前过滤结果。
- 可搜索标题、项目或仓库并多选；勾选与预览独立，点击标题展示右侧详情，不改变勾选状态。列表为勾选框、单行省略标题、右侧来源名称（如 GitHub），不显示项目副标题或眼睛预览按钮，不显示勾选说明文案。
- 紧凑搜索框与服务商、仓库和任务关联筛选位于同一行，窄窗口时工具栏允许横向滚动，不将搜索框拉满弹窗。筛选固定文案随应用语言切换：默认分别为“全部服务商 / Any provider”“全部仓库 / Any Repo”“未关联任务 / Not task yet”。关联选项为“不限 / Any”“已关联任务 / Has a task”“未关联任务 / Not task yet”；服务商和仓库名称不翻译，各维度与搜索取交集。
- 列表与预览为独立滚动的两块区域，中间保留 8px 可拖动分隔条，可使用左右方向键调整宽度；接近均分时吸附，不显示比例文字或特殊颜色。两侧有最小宽度限制，筛选和勾选不重置比例，重新打开弹窗恢复默认比例。
- 服务商与仓库选项来自当前类别完整数据集；缺少来源的旧数据展示“未知来源”，不推断为 GitHub。缺少仓库字段时沿用现有项目名进行仓库筛选，不宣称已接入远程同步。
- 关联 PR 额外提供状态筛选，位于仓库与任务关联筛选之间，默认“全部状态 / Any State”，选项为“全部状态 / Any State”“开放 / Open”“草稿 / Draft”。当前本地数据中 Open 对应待审查的非草稿 PR，Draft 对应草稿；全部状态包含已合并条目。与其他筛选取交集，不清空隐藏选择；关联 Issue 不展示也不应用此项。
- 关联状态依据已保存任务的 Issue/PR 关联判断，包含已完成和归档任务，不计入尚未提交的创建草稿。关联数据未读取完成时不将条目误判为未关联，读取失败提供重试。
- 筛选不清空已勾选条目，确认时保留被筛选隐藏的选择；取消不修改草稿。预览条目被筛选隐藏时清空预览展示。重新打开弹窗恢复默认筛选，保留草稿已有选择。
- 确认替换该类别的草稿选择，取消不改变原选择；返回后展示可移除条目。
- 只预览已有标题、项目、状态、时间等真实字段，不虚构正文、作者或远程筛选能力。

## 4. 工作目录选择与配置

- 与设置中的仓库和文件夹共用资源列表，支持搜索、多选及快捷添加；快捷添加复用已有仓库弹窗。
- 快捷新增的资源立即保存到全局列表，设置页和选择器均可见，取消任务不删除此记录。
- 所选资源使用紧凑单行布局，仅展示名称，不展示实际路径；可移除并继续添加。以实际路径和 Git 根目录防止重复关联。
- 目录区域不显示“工作目录”标题或可选提示文案，未添加资源时在输入框下方靠左展示“添加仓库或文件夹”按钮。有资源后仅展示加号图标入口，紧跟最后一个目录组合控件，不另占一行；移除全部资源后恢复文字按钮。图标保留提示及可访问名称。
- 每行采用按内容增长的相连组合控件，不铺满容器、不设置整行最小宽度；内部无间隔、仅保留单条分隔边界，圆角只出现在整行两端。长名称省略显示并可悬停查看完整内容。
- 名称、源分支、目标分支、Worktree 复选框及移除操作合并为一行，不展示执行模式下拉框，普通文件夹仅展示名称和移除。目录列表限制高度，多个目录时内部滚动；窄窗口允许列表横向滚动，不将配置堆成多行。
- 点击名称打开可搜索的资源下拉列表，不打开替换弹窗，选择即生效；已关联的其他资源及不可用路径禁止选择。切换成功后源分支重置为新仓库的默认源分支，目标分支清空、执行模式回到设置默认值；探测失败保留原配置并提示错误。
- 实际探测 Git 能力，不能只依据资源类型。普通文件夹不展示分支和 Worktree 配置。
- 每个仓库初始配置取设置中的任务执行模式，默认勾选独立 Worktree。选择普通源分支时始终创建新分支，Worktree 复选框仅决定是否同步创建独立工作区，不提供“原仓库新建分支”选项。
- 源分支菜单顶部提供“使用当前分支”，选择后显示仓库实际当前分支，隐藏目标分支控件并清空其草稿，Worktree 取消勾选并禁用。不创建或切换分支，不创建 Worktree，允许保留现有工作区内容；分离 HEAD 时明确展示该状态。
- 从“使用当前分支”切回任意普通源分支（包括同名本地分支）后恢复目标分支按钮并创建新分支，可重新勾选 Worktree。
- 源分支菜单可搜索，分本地与远程组，使用完整引用消除重名歧义；优先远程默认分支，再选择已有主分支或当前分支。不会暗示已自动联网刷新远程。
- 目标分支未填写时使用设置前缀加八位随机短 ID，不附时间戳；前缀为空直接用短 ID，手填名称不附加前缀。
- 目标分支默认显示“Branch Name”按钮，点击后原位切换为输入框及取消、确认图标按钮。确认后保存填写内容并回到按钮展示该名称；取消丢弃本次编辑并恢复原值。确认空值恢复“Branch Name”及自动命名规则，未确认输入不用于创建任务。
- 编辑状态支持 Enter 确认、Esc 取消，Esc 不关闭创建任务弹窗；输入法组合输入期间不触发确认。
- 自动名冲突重新生成，手填冲突提示修改；校验 Git 分支名，绝不覆盖已有分支。
- Worktree 放在设置目录下，以任务与资源区分路径。原目录新建/切换分支要求没有未提交改动，不自动 stash、丢弃或覆盖。

## 5. 文件附件与普通链接

- 原生文件选择器只选择文件，可多选，不选择目录。创建弹窗中图片和其他文件均使用链接图标加文件名回显，不显示缩略图、文件类型图标或大小；保留移除按钮，长文件名省略并可悬停查看完整名称。
- 创建时复制到应用管理目录，源文件不会被修改；移除草稿引用不删除源文件。
- SQLite 保存附件元信息而非原文件二进制，任务详情可展示文件条目和可用的小图片预览。
- 文件失效时提示重新选择，不因附件错误清空描述或其他配置。
- “添加链接”打开叠加子弹窗，包含必填链接和选填标题；字段标签仅显示“链接”“标题”，不标注必填或选填，标题输入框以“选填 / Optional”作为占位提示。底部显示说明及“添加”按钮。取消、Esc 或点击遮罩只关闭当前子弹窗，回到附件入口，不修改已有草稿。
- 链接与标题去掉首尾空白；只接受有效的 HTTP/HTTPS 网页地址，不接受内嵌账号密码、脚本或本地文件协议。链接最多 8192 个字符，标题最多 200 个字符；链接为空时不可添加，无效地址在表单内提示。
- 说明随界面语言切换。英文为“Any url - docs, a spec, a ticket. Add a title to label the row, or leave it and the url shows.”；中文说明可添加文档、规范、工单等网页链接，标题留空则显示 URL。
- 确认后在组合输入区内显示链接图标及标题，未填标题显示 URL；长文案省略，悬停可查看完整 URL，支持独立移除。
- 普通链接与 Issue/PR 关联独立保存，不自动识别或转换平台条目，不抓取网页标题、正文或状态。链接随任务保存到 SQLite，重启后保留，侧栏和任务页均展示标题或 URL。

## 6. 提交、持久化与恢复

- 完成校验后准备附件和工作区，全部成功后保存任务及关联记录，新增任务进入 TODO，按当前排序属性和方向展示。
- 创建成功转到 Tasks 并打开独立详情；若被筛选隐藏，提供查看入口，由用户清除筛选后查看。
- 同一提交重试不得重复创建任务。任务及关联存入 SQLite，资源目录仍复用已有存储服务。
- Git、文件系统与数据库不具备统一事务；按操作清单处理失败及启动恢复。
- 只撤销本次确认生成、HEAD 未变化且没有用户改动的工作区和分支；无法确认归属或存在改动时保留并提示检查。
- 创建失败的回滚和任务归档不会强制清理用户改动；删除任务默认保留目录和分支，仅在用户查看实时风险清单并明确勾选清理后，才删除可确认归属的独立 Worktree 及可选本地分支。使用当前分支、普通目录及原仓库新建分支均保留原目录、分支和修改，详见 Tasks 页的删除规则。

## 7. 验收标准

- 顶部按钮可创建任务，成功后进入 Tasks 侧栏预览，不自动新增任务标签。
- 描述生成标题，Issue/PR 多选预览与取消正确，资源选择和设置列表共享数据。
- 三类关联筛选默认值与组合结果正确，已关联任务条目默认隐藏，筛选切换不丢失勾选；长标题单行省略，右侧显示来源且不显示眼睛图标或项目副标题。
- 多仓库可独立配置执行模式、源分支及目标分支，普通目录不显示 Git 控件。
- 短名称遵循前缀、手填和冲突规则；不覆盖分支、未提交改动或既有路径。
- 附件仅选文件，复制后不依赖原文件继续存在，移除不误删原文件。
- 附件入口菜单提供两项操作；普通链接的必填校验、可选标题、回显、移除、草稿保留和重启恢复正确；关闭链接子弹窗不连带关闭创建表单。
- TODO 入列、详情、重启恢复及旧任务迁移正确，失败保留草稿与必要现场。
