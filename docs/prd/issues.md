# Issue 页面

[产品需求索引](../../PRD.md) · [导航与共用详情](workspace.md)

## 1. 页面范围与数据

展示 PR 与 ISSUE 两类条目，每项包含唯一标识、分组、标签、标题、项目、状态和时间。当前仅展示本地条目，不发起远程平台授权、同步或状态修改。开发与正式环境均不预置演示条目；加载时清理可确认身份的历史演示条目，保留其他本地记录。无数据时显示空状态，创建任务中的关联选择器使用同一数据源。

## 2. 功能与交互

- 默认使用列表，可切换为看板；两种视图均按 PR 和 ISSUE 分组。列表分组默认展开，点击分组标题可收起和展开，切换视图保留列表折叠状态。
- 左侧按标签、标题排列；右侧按项目名、状态、时间自然宽度居右排列，不使用固定表格列宽。
- 状态通过文字和颜色区分，不显示状态图标。
- 切换条目不改变分组展开状态。
- 右上角提供过滤与显示选项。过滤支持分组、状态、项目和标签多选；同类条件取并集，不同条件取交集，不提供标题搜索。选项显示基于完整条目集合的数量，不显示已选数量，可一键重置。
- 列表与看板仅展示含匹配条目的 PR 或 ISSUE 分组，空分组不展示标题、计数或占位列；分组数量显示当前匹配条目数。过滤不会重置分组折叠状态，详情只显示当前结果中的条目。
- 显示选项支持列表/看板切换、日期/标题/项目名属性排序，以及标签、项目、状态和时间显隐；标题始终显示，详情仍显示完整元信息。两种视图共享筛选、排序、字段显隐和详情选中项。
- 看板以 PR 和 ISSUE 为两列；列表和看板都不支持手动拖拽排序，也不允许通过拖拽修改 PR/ISSUE 类型或条目状态。
- 排序由独立的升降序图标按钮和属性下拉列表组成，默认日期降序，切换属性保留方向；只改变组内展示，不修改原始数据。属性相同时使用稳定次序。
- Issue 的过滤与显示设置独立于 Tasks，切换模块后保留，本阶段不跨重启保存。
- 显示选项右侧提供刷新按钮，仅重新读取当前本地条目数据源，不宣称已同步远程平台。刷新保留过滤和显示设置，并按当前排序规则展示，内容及增删结果以数据源为准。
- 刷新期间禁用按钮，完成后进入 60 秒冷却，失败也不绕过冷却；倒计时仅在 tooltip 中展示，禁用期间仍可悬停查看。冷却与 Tasks 独立，切换模块或显示方式不重置；不持久化，冷重启应用后可立即刷新。

点击条目在独立右侧详情块中展示标题和完整元信息，不自动进入 diff。无数据或无匹配结果时隐藏全部分组，在工具栏下方显示统一空状态，不改变已有分组展开状态；工具栏仍可使用。

原始数据为空时，英文标题为 “No assigned PRs or issues”，说明为 “This list shows work you authored, are assigned, or were mentioned in. To browse everything else in your organizations, use New task → Issues > All visible.”；中文提供对应翻译。已有数据但被筛选全部隐藏时，仅显示“暂无匹配条目”，不显示未分配提示。本次仅约定空状态说明，不新增服务商授权、远程条目获取或 All visible 筛选能力。

## 3. 页面布局与控件

- 外部 padding 16px，PR 和 ISSUE 分组间隔 12px。
- 顶部工具栏与 Tasks 一致，高 48px、左右内边距 16px；右侧依次为重置、过滤、显示选项和刷新，左侧不显示条目总数，列表独立滚动。
- 过滤与显示弹层沿用 Tasks 的统一宽度、内边距、主题圆角和缩进分割线。过滤包含分组、状态、项目与标签二级多选菜单，子项仅显示文字、条目数量和选中标记，重置位于右下角。
- 显示选项顶部提供列表/看板切换，其余为排序方向图标、属性下拉列表及标签、项目、状态、时间字段胶囊按钮，隐藏字段后不留下空白单元格。
- 看板沿用 Tasks 的列、卡片和动效风格，PR 在左、ISSUE 在右；筛选仅保留一种类型时该列占满可用宽度，空间不足时横向滚动。卡片展示标签、标题及项目、彩色状态和时间，点击后打开同样的独立详情块。
- 分组标题高 44px，默认展开，带方向箭头和数量，收起展开约 200ms。
- 每行最小高度 56px、左右 padding 16px；左侧标签后跟标题，右侧项目、状态、时间使用自然宽度靠右排列，间距 16px。
- 标题省略时提供完整提示；状态仅用彩色文字，不显示图标；不使用固定列宽或表格单元格。
- 点击行打开同样的独立详情面板，选中行有克制的浅色背景。

## 4. 验收标准

- 有数据的 PR、ISSUE 默认展开，点击分组标题可独立收起与展开；空分组隐藏，仅一种类型有数据时看板展示单列。
- 列表和看板全空时均无分组占位，展示未分配标题及说明；筛选无匹配结果使用独立提示。中英文切换即时更新，数据恢复后保留原有分组折叠状态。
- 左侧标签加标题；右侧项目、彩色状态文字和时间自然宽度居右，状态无图标。
- 分组、状态、项目、标签多选与重置正确，选项数量按完整数据统计。
- 过滤不删除记录、不重置分组状态，详情不展示已被过滤掉的条目。
- 属性排序只在组内生效；隐藏字段后无空白单元格，详情仍显示完整信息。
- 显示和过滤偏好独立于 Tasks，同一窗口切换模块后保持。
- 列表/看板切换不会重置筛选、排序、字段显隐、详情选中项和列表折叠状态。
- 不提供自定义顺序选项，列表与看板均不支持手动排序或跨类型拖拽。
- 筛选不删除隐藏条目；切换排序属性保留升降序方向，切换布局保留完整排序配置。
- 刷新更新本地条目但保留排序设置、过滤和显示方式；冷却 60 秒内不能再次刷新，tooltip 实时倒计时，到期自动恢复，冷重启不恢复冷却。
