# Issue 页面

[产品需求索引](../../PRD.md) · [导航与共用详情](workspace.md)

## 1. 页面范围与数据

展示 PR 与 ISSUE 两类条目，每项包含唯一标识、分组、标签、标题、项目、状态和时间。当前仅展示本地条目，不发起远程平台授权、同步或状态修改，不将示例数据表示为真实远程数据。

## 2. 功能与交互

- 默认使用列表，可切换为看板；两种视图均按 PR 和 ISSUE 分组。列表分组默认展开，点击分组标题可收起和展开，切换视图保留列表折叠状态。
- 左侧按标签、标题排列；右侧按项目名、状态、时间自然宽度居右排列，不使用固定表格列宽。
- 状态通过文字和颜色区分，不显示状态图标。
- 切换条目不改变分组展开状态。
- 右上角提供过滤与显示选项。过滤支持分组、状态、项目和标签多选；同类条件取并集，不同条件取交集，不提供标题搜索。选项显示基于完整条目集合的数量，不显示已选数量，可一键重置。
- 分组筛选只显示选中的 PR 或 ISSUE 分组；分组数量显示当前匹配条目数，无匹配时显示空提示。过滤不会重置分组折叠状态，详情只显示当前结果中的条目。
- 显示选项支持列表/看板切换、自定义顺序、组内时间升降序，以及标签、项目、状态和时间显隐；标题始终显示，详情仍显示完整元信息。两种视图共享筛选、排序、字段显隐和详情选中项。
- 看板以 PR 和 ISSUE 为两列，自定义顺序下支持同类型卡片拖拽排序，使用空框占位及让位、落位动画；PR 不可拖入 ISSUE，ISSUE 也不可拖入 PR，跨类型放下或按 Escape 取消时保持原顺序。时间排序下禁用拖拽，切回自定义顺序恢复手动排列。
- 拖拽仅调整当前窗口内的本地顺序，不改变类型、状态或远程数据；筛选后的拖拽不丢失隐藏条目。列表同步展示手动顺序，时间排序不覆盖手动顺序。
- Issue 的过滤与显示设置独立于 Tasks，切换模块后保留，本阶段不跨重启保存。
- 显示选项右侧提供刷新按钮，仅重新读取当前本地条目数据源，不宣称已同步远程平台。刷新保留过滤、显示设置和仍存在条目的手动顺序，内容及增删结果以数据源为准。
- 刷新期间禁用按钮，完成后进入 60 秒冷却，失败也不绕过冷却；倒计时仅在 tooltip 中展示，禁用期间仍可悬停查看。冷却与 Tasks 独立，切换模块或显示方式不重置；不持久化，冷重启应用后可立即刷新。

点击条目在独立右侧详情块中展示标题和完整元信息，不自动进入 diff。无数据或无匹配结果时显示相应空提示，不改变已有分组展开状态。

## 3. 页面布局与控件

- 外部 padding 16px，PR 和 ISSUE 分组间隔 12px。
- 顶部工具栏与 Tasks 一致，高 48px、左右内边距 16px；右侧依次为重置、过滤、显示选项和刷新，左侧不显示条目总数，列表独立滚动。
- 过滤与显示弹层沿用 Tasks 的统一宽度、内边距、主题圆角和缩进分割线。过滤包含分组、状态、项目与标签二级多选菜单，子项仅显示文字、条目数量和选中标记，重置位于右下角。
- 显示选项顶部提供列表/看板切换，其余为排序选择及标签、项目、状态、时间字段胶囊按钮，隐藏字段后不留下空白单元格。
- 看板沿用 Tasks 的列、卡片和动效风格，PR 在左、ISSUE 在右；筛选仅保留一种类型时该列占满可用宽度，空间不足时横向滚动。卡片展示标签、标题及项目、彩色状态和时间，点击后打开同样的独立详情块。
- 分组标题高 44px，默认展开，带方向箭头和数量，收起展开约 200ms。
- 每行最小高度 56px、左右 padding 16px；左侧标签后跟标题，右侧项目、状态、时间使用自然宽度靠右排列，间距 16px。
- 标题省略时提供完整提示；状态仅用彩色文字，不显示图标；不使用固定列宽或表格单元格。
- 点击行打开同样的独立详情面板，选中行有克制的浅色背景。

## 4. 验收标准

- PR、ISSUE 默认展开，点击分组标题可独立收起与展开。
- 左侧标签加标题；右侧项目、彩色状态文字和时间自然宽度居右，状态无图标。
- 分组、状态、项目、标签多选与重置正确，选项数量按完整数据统计。
- 过滤不删除记录、不重置分组状态，详情不展示已被过滤掉的条目。
- 时间排序只在组内生效；隐藏字段后无空白单元格，详情仍显示完整信息。
- 显示和过滤偏好独立于 Tasks，同一窗口切换模块后保持。
- 列表/看板切换不会重置筛选、排序、字段显隐、详情选中项和列表折叠状态。
- 看板支持同类型拖拽到首位、中间和末尾；跨类型拖拽不能改变类型或顺序，取消拖拽不打开详情。
- 筛选后排序保留隐藏条目；时间排序下不可拖拽，切回自定义顺序后恢复手动排列。
- 刷新更新本地条目但保留手动顺序、过滤和显示方式；冷却 60 秒内不能再次刷新，tooltip 实时倒计时，到期自动恢复，冷重启不恢复冷却。
