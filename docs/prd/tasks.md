# Tasks 页面

[产品需求索引](../../PRD.md) · [导航与共用详情](workspace.md)

## 1. 页面范围与数据

任务包含唯一标识、标题、日期、项目名、状态和排列顺序。状态固定为 TODO、DONE、ARCHIVED，不将旧审查会话自动转为任务。当前不提供任务创建或真实 Agent 运行入口。

任务顺序与状态持久化到本地；退出后恢复。开发示例与正式数据分开，无数据时各列展示空提示，不引导开启 hooks。

## 2. 功能与交互

- 固定三列：TODO、DONE、ARCHIVED，列标题显示当前任务数量。
- 卡片只展示标题、日期与项目名，标题超长时最多显示两行。
- 支持同列前后排序及跨列放到指定位置，数量在落位后同步更新。
- 拖动时使用页面内圆角浮动卡片，目标位置显示同尺寸空白框；状态列不显示拖拽描边。
- 拖拽不会触发详情打开；取消拖拽保持原状态和顺序。
- 排序与状态变化保存到本地，退出后重新打开可恢复。
- 面板右上角提供过滤和显示选项两个按钮。过滤支持状态多选与项目多选，不提供任务标题搜索框；同类条件取并集，不同条件取交集，可一键重置。
- 列数量显示筛选后的任务数，详情仅显示当前结果中的任务；筛选不会删除任务或覆盖其元数据。
- 显示选项支持看板与按状态分组的列表、自定义顺序或日期升降序，以及日期/项目字段显隐。标题始终显示，详情不受字段显隐影响。
- 列内与跨列拖拽仅在看板的自定义顺序下可用；日期排序只影响展示，不覆盖已保存的任务顺序，列表仍支持点击打开详情。
- 过滤和显示设置在当前窗口内保留，切换模块不重置；本阶段不跨重启保存。

点击任务遵循共用详情规则，展示标题及元信息；详情随状态变更同步更新。筛选使已选任务不可见时不继续展示该任务详情，但不删除其记录。

## 3. 页面布局与控件

- 固定三列，每列 minmax(260px, 1fr)，容器 gap 和 padding 均 12px。
- 状态列圆角 12px，背景接近主面板，不形成明显第三层灰块；标题 padding 为 0 16px，卡片区为 0 12px 12px。
- 卡片圆角 10px、内边距 16px、最小高度 106px，标题最多两行，仅显示标题、日期与项目名。
- 面板顶部工具栏高 48px、左右内边距 16px；左侧不显示任务总数，右侧为重置入口及 28px 过滤和显示选项图标按钮，间隔 8px。重置入口在启用过滤时显示。
- 过滤沿用 shadcn 下拉菜单，不提供标题搜索或“添加过滤条件”提示；主面板与显示选项统一宽 288px、内边距 16px、主题圆角、底色和轻量阴影，分区使用随内容缩进的主题分割线，线上下间距均为 16px。状态与项目通过二级菜单多选，选项右侧显示对应任务的条目数量，以完整任务集合统计，不显示已选数量。子菜单选项不使用装饰图标，仅保留文字、条目数量和选中标记。启用过滤时按钮显示轻量标记，菜单底部的重置操作靠右排列。
- 显示选项使用 Radix 弹层，宽 288px、内边距 16px，提供列表/看板分段切换、排序选择和日期/项目字段胶囊按钮，不引入任务数据中不存在的字段。
- 列表仍按 TODO、DONE、ARCHIVED 分组，组间距 12px，任务标题居左，项目与日期自然宽度居右；使用相同的独立详情布局。
- 卡片间距 10px；默认光标，文字不可选择；选中卡片轻量描边。
- 使用页面内浮动卡片，圆角外侧透明；目标位置是等高空白框，不是细线，也不描边整列。
- 让位动画约 200ms，松手落位约 180ms；Escape 或无效落点取消拖动。

## 4. 异常边界

- 取消拖动或无效落点不改变状态和顺序，拖动不会误触详情。
- 过滤后的排序不得删除隐藏任务或改变其元数据，隐藏任务的相对顺序保持不变。
- 无任务与无筛选结果均提供空提示；错误或重复标识不进入看板。
- 日期排序只是展示排序；回到自定义排序后恢复原有顺序。

## 5. 验收标准

- 三列、卡片字段、数量与筛选结果一致。
- 看板自定义顺序支持同列前后排序、跨列指定位置和空列落位，退出后可恢复。
- 拖动为圆角浮动卡片及等高框占位，无专用拖动图标和整列描边。
- 状态/项目多选、重置、看板/列表切换、日期排序和字段显隐互不破坏任务数据。
- 过滤和显示选项跨模块保留，但不承诺跨重启保存。
- 点击卡片打开独立详情，关闭后恢复完整任务面板。
