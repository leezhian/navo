# Tasks 页面

[产品需求索引](../../PRD.md) · [导航与共用详情](workspace.md)

## 1. 页面范围与数据

任务包含唯一标识、标题、日期、项目名和状态。状态固定为 TODO、DONE、ARCHIVED，不将旧审查会话自动转为任务。顶部提供[创建任务](task-create.md)入口，带 Agent 配置的任务保存后独立启动首个 CLI 会话。

任务数据与状态持久化到本地；退出后恢复。组内展示顺序由排序属性与方向决定，不提供手动排列。开发与正式数据分开，均不预置演示任务；无数据时各列展示空提示，不引导开启 hooks。

任务分别记录创建日期和自身更新时间。创建时两者相同，重命名、状态变更、实际新增或修改关联资源时更新自身更新时间；重复提交、无变化操作、读取及刷新不更新时间，也不因其他任务或会话活动改动。旧任务以原创建日期回填，不将升级时间当作更新时间。当前卡片日期展示及日期排序仍使用创建日期。

卡片和列表日期统一使用相对时间：不足 1 分钟为 `just now`，不足 1 小时为 `5m ago`，不足 24 小时为 `2h ago`，24 小时至 30 天为 `3d ago`，超过 30 天显示本地日期 `yyyy.mm.dd`；恰好 30 天仍显示 `30d ago`。分钟、小时、天数向下取整，中文环境显示对应中文文案。相对时间共用每分钟刷新的时钟，重新显示页面时更新；卡片时间不显示悬停提示，列表时间悬停仍可查看完整本地日期和时间，不影响日期字段显隐及排序规则。

## 2. 功能与交互

- 固定三列：TODO、DONE、ARCHIVED，列标题显示当前任务数量。
- 卡片展示标题、会话汇总、日期与项目名。标题最多两行，超出省略，连续长字符串也可换行；列表标题保持单行省略。卡片项目名位于标题下方，时间位于右下角，不展示分支；项目和日期继续由显示选项独立控制。多个资源显示首个项目名称及 +N，悬停查看完整项目名称，无关联资源显示“未关联项目”；项目过滤匹配任一关联资源，选项数量以完整任务集合计算。
- 看板卡片和列表行的标题旁按状态汇总未归档 Agent 会话：同状态合并为一个小图标，不同状态并列展示，每组只有 1 个会话时不显示数字，超过 1 个才显示该组数量，不把所有会话总数作为某一个状态的数量。无会话时隐藏整个标记，不显示 0。悬停逐项展示本地化状态和数量，辅助技术可读取总数与各组明细。
- 分组按失败、运行中、启动中、已停止排序，先暴露异常；运行中为实心标记、启动中有轻量旋转反馈，失败和停止采用静态空心图标，不仅依赖颜色区分。只统计当前任务的 Agent 会话，普通终端、其他任务及已归档会话不参与；停止或失败但未归档的会话仍计数。状态变化或归档后实时更新，不要求刷新任务列表。
- 标签页仍仅显示一个代表状态，与任务 TODO/DONE 独立：运行中、启动中优于失败、已停止。分组展示顺序与代表状态优先级用途不同。当前 CLI 仅确认这四种状态，不推断等待输入、未读、暂停或保留最后状态的休眠会话；后续取得可靠信号后再扩展。
- 看板和列表均支持跨状态组拖拽，例如 TODO 移到 DONE；不支持同组内手动排序。放下后按当前排序属性和方向自动排列，数量在落位后同步更新。
- 拖动时使用页面内圆角浮动卡片，源位置保留同尺寸空白框；有效目标状态组仅以轻量背景高亮反馈，不展示提示文案或实际落位位置，不描边状态列。同状态组和视图外不显示接收反馈。
- 拖拽不会触发详情打开；取消拖拽保持原状态和顺序。
- 拖拽只提交状态变化并保存到本地，不按鼠标位置修改组内顺序。
- 面板右上角依次提供过滤、显示选项和刷新按钮。过滤支持状态多选与项目多选，不提供任务标题搜索框；同类条件取并集，不同条件取交集，可一键重置。
- 刷新重新读取本地任务数据，不重载窗口、不清空现有列表、不重置筛选和显示选项。数据加载或写入期间禁用刷新；刷新完成后进入 60 秒冷却，失败也不绕过冷却，剩余秒数仅在 tooltip 中显示。禁用期间仍可查看 tooltip。
- 冷却与 Issue 独立，切换模块、列表/看板后继续计时；冷却不持久化，冷重启应用后可立即刷新。
- 列数量显示筛选后的任务数，详情仅显示当前结果中的任务；筛选不会删除任务或覆盖其元数据。
- 显示选项支持看板与按状态分组的列表、日期/标题/项目名属性排序，以及日期/项目字段显隐。排序由独立的升降序图标按钮和属性下拉列表组成，默认日期降序；切换属性保留方向，属性相同时使用稳定次序。标题始终显示，详情不受字段显隐影响。
- 列表和看板共享排序配置，所有排序属性与方向下都允许跨状态拖拽。同组、视图外放下或 Escape 取消均不修改状态，不保存顺序，也不触发打开详情。
- 列表的 TODO、DONE、ARCHIVED 分组默认展开，可点击分组标题或通过键盘独立展开、收起。标题保留任务数量与方向箭头；折叠不改变筛选、任务数据或详情。切换布局、模块、排序或刷新时保留折叠状态，本阶段不跨重启保存。
- 收起的分组标题仍可接收跨状态拖拽，成功移入后更新数量但保持收起，不自动展开。
- 过滤和显示设置在当前窗口内保留，切换模块不重置；本阶段不跨重启保存。

点击任务时若已有任务标签则直接激活该页面，否则打开右侧详情。侧栏与任务页共用[任务工作台](task-workspace.md)，展示真实 CLI、终端、分类资源导航，并随任务变更同步更新。普通链接显示自定义标题，未填写时显示 URL，悬停可查看完整地址，不自动抓取网页或转换为 Issue/PR。筛选使侧栏所选任务不可见时不继续展示侧栏，但不删除任务或关闭已打开的标签页。

侧栏关闭按钮旁提供“打开任务页面”按钮，点击后收起侧栏并在顶部添加、激活唯一的任务标签；任务页占据主内容区，不额外创建工作目录或启动 Agent。任务页面切换保留运行进程和终端输出，点击左侧 Tasks 返回原面板与筛选设置；关闭最后一个标签返回面板。

任务标签可按[应用壳层](workspace.md)规则组成双页拆分视图。点击已属于组合的任务时激活整个组合并聚焦对应页面；拆分和互换只改变页面组织，不修改任务内容或工作目录。

## 3. 页面布局与控件

- 固定三列，每列 minmax(260px, 1fr)，容器 gap 和 padding 均 12px。
- 状态列圆角 12px，背景接近主面板，不形成明显第三层灰块；标题 padding 为 0 16px，卡片区为 0 12px 12px。
- 卡片圆角 10px、内边距 16px、最小高度 96px，标题最多两行，项目名位于标题下方，日期位于右下角；会话标记继续与标题并列。
- 面板顶部工具栏高 48px、左右内边距 16px；左侧不显示任务总数，右侧为重置入口及 28px 过滤、显示选项和刷新图标按钮，间隔 8px。重置入口在启用过滤时显示，刷新位于最右侧，刷新中图标旋转并禁用。
- 过滤沿用 shadcn 下拉菜单，不提供标题搜索或“添加过滤条件”提示；主面板与显示选项统一宽 288px、内边距 16px、主题圆角、底色和轻量阴影，分区使用随内容缩进的主题分割线，线上下间距均为 16px。状态与项目通过二级菜单多选，选项右侧显示对应任务的条目数量，以完整任务集合统计，不显示已选数量。子菜单选项不使用装饰图标，仅保留文字、条目数量和选中标记。启用过滤时按钮显示轻量标记，菜单底部的重置操作靠右排列。
- 显示选项使用 Radix 弹层，提供列表/看板分段切换、排序方向图标与属性下拉列表，以及日期/项目字段胶囊按钮，不引入任务数据中不存在的字段。方向图标 tooltip 提示当前方向和切换动作，不提供自定义顺序选项。
- 列表仍按 TODO、DONE、ARCHIVED 分组，组间距 12px，分组标题带折叠箭头，展开收起约 200ms，尊重减少动态效果设置。任务标题居左，项目与日期自然宽度居右；使用相同的独立详情布局。
- 卡片间距 10px；默认光标，文字不可选择；选中卡片轻量描边。
- 使用页面内浮动卡片或列表行，圆角外侧透明，只有源位置保留等高空框；目标组不插入空框、不挤动现有条目，只反馈是否可以移入。
- 有效放下后浮动卡片约 180ms 淡出，随后提交状态并按当前属性排序；Escape 或无效落点取消拖动，清除分组高亮。

## 4. 异常边界

- 取消拖动或无效落点不改变状态和顺序，拖动不会误触详情。
- 筛选后的跨状态拖拽不得删除隐藏任务或改变其元数据。只能拖入当前可见的状态组。
- 无任务与无筛选结果均提供空提示；错误或重复标识不进入看板。
- 属性排序只影响组内展示，不改变固定的状态分组顺序，也不写入排序偏好到持久化存储。

## 5. 任务菜单与持久化

- 卡片和列表行均支持右键菜单：打开、以标签页打开、重命名、添加资源、归档、删除。“打开”优先激活已有任务标签，无标签时展示右侧详情，不自动新增标签。
- “以标签页打开”位于“打开”下方，直接新增并激活任务标签，同时收起任务侧栏；已有标签则直接激活，不重复创建。任务已属于拆分组合时，保留组合并聚焦对应任务。
- 同一任务连续右击时，菜单跟随最新鼠标位置，并保持窗口边缘避让。
- 添加资源打开任务工作台共用的资源窗口，将仓库/文件夹、Issue/PR、笔记、链接或原文件直接绑定当前任务；仓库可配置源分支及隔离 Worktree，沿用工作台的安全创建与回滚规则。已归档任务不显示该项，并将归档替换为恢复。
- 归档记录原 TODO 或 DONE 状态，恢复回到原状态；旧归档任务缺省恢复 TODO。拖拽与菜单使用一致的状态规则。
- 重命名要求非空标题，最多 160 字，只修改标题，不修改描述或分支。
- 删除需打开独立确认弹窗，显示任务名称、关联记录及应用管理附件副本的删除范围，并提醒无法撤销；同时说明任务会话与终端将停止、Agent 会话记录将删除。默认仅删除任务，不删除原文件、全局资源记录或原仓库。
- 能确认归属的独立 Worktree 提供“同时删除 Worktree”；勾选后才显示“同时删除本地分支”，取消前者会重置后者。每次打开均不勾选，不记忆破坏性选项。全部使用当前分支、普通文件夹、原仓库新建分支或无法证明归属的旧任务不提供清理选项，并说明现有目录及分支保留。
- 选择清理后按项目展示“将被删除”“保留”及中断清理后“已完成”的清单。分别说明未提交文件、未跟踪文件、会随目录删除的忽略文件、Detached HEAD 和可能丢失的本地提交。提交风险只依据本地远端跟踪引用，不联网核实；没有远端引用时明确无法确认是否推送，不宣称安全。
- 清理仅作用于任务创建且文件系统身份仍匹配的独立 Worktree 与对应本地分支。共享工作区、仓库主工作区、锁定工作区、被其他工作区或任务使用的分支、常见主分支和本地远端 HEAD 指向的分支均保留；不会删除远端分支、远端 Issue/PR 或原始附件。资源缺失、路径替换或无法证明归属时不扩大清理范围；无法完整检查时可重试或取消清理选项，仅删除任务。
- 同一仓库的多个 Worktree 按独立工作区标识逐项检查和清理，不因仓库相同而遗漏或合并。复用外部已有 Worktree 不取得清理权限；以已有分支新建的托管 Worktree 可清理目录，但不删除原有分支。
- 弹窗沿用项目基础组件，约 480px 宽；多项目清单限高滚动，按钮区域保持可见。初始焦点在取消按钮，检查未完成时禁用删除；关闭按钮、Esc 和外部点击均只取消确认。执行期间禁止关闭和重复提交。
- 删除确认绑定当前任务、窗口及检查范围，执行前再次核实资源身份、文件状态和分支提交；发生变化则展示更新清单，必须再次点击“删除任务”，不自动重试破坏性操作。
- 清理按 Worktree、本地分支、附件副本、任务记录执行，并记录每个工作区已完成的步骤。部分失败保留任务和错误提示，已清理的文件不能撤销；重新打开或重启后显示可识别的进度，必须重新确认才继续，亦可取消清理以保留剩余资源。删除成功才移除任务侧栏与标签，拆分组合沿用关闭单页规则。归档仍只改变状态，不附带磁盘清理。
- 任务、关联元信息和归档前状态保存到 SQLite；旧任务在数据库尚未初始化时迁移，保留标识和顺序，成功后才清理旧任务键。
- 无数据时保持空列表，不自动填充演示任务。升级及旧数据导入时仅清理身份匹配且未添加真实上下文的历史演示任务，以及可确认的演示 Issue/PR 关联；不删除真实任务、设置、仓库、分支、Worktree 或附件。开发与正式任务独立，存储失败可见，不伪装成功。
- 创建成功进入 TODO，按当前排序规则展示，并请求打开详情。若筛选隐藏新任务，提供查看入口，由用户清除筛选查看。

## 6. 验收标准

- 三列、卡片字段、数量与筛选结果一致。
- 看板和列表均支持跨状态拖拽及空组落位，状态修改可持久化；同组拖动不改变顺序，落位位置由排序属性决定。
- 拖动为圆角浮动卡片及源位置等高框占位；有效目标组仅高亮，不显示提示文案或目标位置占位，无专用拖动图标和整列描边。
- 状态/项目多选、重置、看板/列表切换、排序属性与方向切换和字段显隐互不破坏任务数据。
- 过滤和显示选项跨模块保留，但不承诺跨重启保存。
- 列表分组可独立展开、收起，鼠标与键盘操作均有效；切换视图、刷新后保留折叠状态，收起标题可接收拖拽且不误触展开。
- 刷新重新读取任务，连续点击只发起一次；刷新完成后 60 秒内禁用，tooltip 秒数持续更新，到期恢复。切换页面不重置冷却，冷重启不恢复上次冷却。
- 未打开标签的任务点击后展示侧栏，侧栏可提升为任务页；已有标签的任务点击后直接跳转，关闭标签后再次点击恢复侧栏预览。
