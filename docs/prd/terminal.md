# 任务内终端

[产品需求索引](../../PRD.md) · [任务工作台](task-workspace.md)

## 1. 当前边界

任务工作台提供普通 Shell 抽屉，位于 CLI 会话下方；与 Agent 会话分开管理，使用 Ghostty WASM 与 Canvas 2D 显示终端，沿用主进程 PTY。不恢复旧的全局终端标签。

Agents 设置中的安装、更新和登录终端仍独立于任务。

## 2. 状态与交互

- 顶部终端按钮切换抽屉；没有终端时，无关联目录或仅一个目录直接创建，多目录先选择工作目录。任务内可创建多个，目录在创建时绑定。
- 任务关联多个仓库或文件夹时，顶部终端按钮右侧提供下拉箭头；终端面板和上下文终端分组的加号也打开相同的目录菜单。仓库条目左侧显示分支名，右侧显示仓库名，长文案单行省略；普通文件夹显示文件夹名。选择后立即在对应资源的实际工作目录创建普通 Shell（Worktree 使用 Worktree 目录，而非原仓库目录），自动显示并选中新终端，不启动 Agent、不运行配置脚本。已有终端时顶部主按钮仍只切换显隐。
- 菜单仅列出当前任务已关联的资源；单目录不增加选择步骤，无目录使用任务专属目录。创建期间禁止重复操作，失效或不属于任务的资源由主进程拒绝，不静默退回其他目录。
- 抽屉没有额外的“终端”标题，标签显示实际 Shell 可执行名称加递增编号，例如 zsh1、bash2。编号从 1 开始，关闭不复用，应用重启后重置。
- 每个终端在上下文终端分组中显示，选择定位到对应终端；全部关闭后隐藏分组。顶部按钮右上角显示数量，零个时隐藏。
- 标签关闭表示终止 PTY 及其运行中的子命令，并移除上下文条目；收起抽屉或关闭任务页仅隐藏视图，不停止进程。
- 归档任务未勾选目录清理时保留普通终端；勾选清理 Worktree 时先关闭本任务所有终端再清理目录。初始化命令在任务归档时始终停止，不因恢复任务自动重跑。
- 支持拖动高度及最大化/还原；切换标签不重建进程，不清空输出。
- Shell 正常退出保留输出与条目，用户显式关闭后移除；错误不影响其他终端。应用退出结束所有进程，不跨重启自动恢复 Shell 或输出。

### 2.1 仓库命令终端

- CHANGES 的命令入口使用该仓库在设置中保存的命令，在所选工作区而非原仓库目录运行；命令终端按命令名称显示，与普通 Shell 共用抽屉和进程关闭规则。只接受命令与工作区标识，不接受前端提供的任意脚本。
- 在 macOS/Linux 使用登录 Shell 原样执行已保存的多行脚本；新 Worktree 初始化复用独立命令终端，顺序执行并记录检查点，失败可重试。暂不增加模板变量替换和默认命令固定。Windows 命令执行暂不支持，不能伪造成功。
- 同任务、同工作区、同命令同时只运行一份；不同工作区各自隔离。运行入口展开对应终端但不主动抢焦点，任务切换和隐藏视图不重跑命令。
- 快速结束的命令也能在终端附着后读取输出和退出码；输出缓冲最多保留末尾 262144 个字符，显式关闭时清理。非零退出标记失败；停止执行沿用关闭终端行为，结束进程树并移除该终端。
- 命令记录、输出和脚本不会写入会话持久化记录或诊断日志；日志仅保留运行结果元信息。应用重启不自动恢复或再次执行命令。

### 2.2 终端显示与输入

- Agent、普通 Shell、仓库命令及设置页 CLI 操作使用统一终端组件，保留当前深色配色及 13px 等宽字体。按字体度量适配容器，窗口、分栏及显示器缩放变化后更新尺寸；隐藏区域不向 PTY 提交零尺寸。
- 支持终端颜色、光标、中文及组合输入、文本选择复制、括号粘贴、历史滚动和常见控制键。macOS 使用 Command+C/V/A 复制、粘贴、全选，Control+C 保留中断语义；终端中的 Esc 交给 CLI，不关闭其设置弹窗。
- 点击终端获取输入焦点；仓库命令仅展开输出，不抢焦点。切页、收起和重新打开保留同一个终端画面；阅读历史时新输出不会强制回到底部。运行中的隐藏终端持续维护状态，停止绘制。
- 使用 Command/Control 点击终端 HTTP(S) 链接，在系统浏览器打开；其他协议不交给系统执行。
- 首次附着衔接有界历史回放与实时输出，避免重复；终端画面和历史仅在内存中保存，最多保留 5000 行滚动历史，不跨应用重启保存。快速退出命令仍显示输出与退出码；退出后可选择复制，但禁止输入，不向已退出进程调整尺寸。
- 不新增终端设置页、历史搜索或本机 Ghostty 配置导入。画面渲染错误独立于 Agent 进程状态，不因视图错误重启或终止已有 Agent。

## 3. 验收标准

- 中文组合输入和多行粘贴不丢失、不重复；颜色、光标及 Canvas 画面正确，分栏缩放不产生横向溢出。
- 历史阅读位置、隐藏期间输出及首次附着交接正确；反复关闭终端后不残留 Canvas 或全局监听。
- 实际 Shell 名称、递增编号、角标与上下文条目一致。
- 普通终端使用任务工作目录，不依赖 Agent hooks；目录不存在时报错，不回退到用户目录。
- 多仓库的三个快速入口均可按分支和仓库名称选择目录，传递对应资源标识，新终端绑定正确路径；取消菜单不创建终端，切换已有终端不改变其工作目录。
- 运行命令时关闭终端能停止进程树，其他终端不受影响。
- 任务侧栏小尺寸、独立标签和双页拆分均可操作；折叠、隐藏和切换页面不会重复启动。

任务上下文更新不通过猜测终端回车或重写原始 PTY 输入交付。无任务 MCP 的 CLI 使用实时上下文文件及启动时的读取约定，可从上下文图标复制读取提示；没有独立消息输入框，也不保证模型每轮已读取更新。
