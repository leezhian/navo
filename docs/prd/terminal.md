# 任务内终端

[产品需求索引](../../PRD.md) · [任务工作台](task-workspace.md)

## 1. 当前边界

任务工作台提供普通 Shell 抽屉，位于 CLI 会话下方；与 Agent 会话分开管理，沿用 VT 渲染及主进程 PTY。不恢复旧的全局终端标签。

Agents 设置中的安装、更新和登录终端仍独立于任务。

## 2. 状态与交互

- 顶部终端按钮切换抽屉；没有终端时创建一个。任务内可创建多个，目录按任务工作目录规则选择并在创建时绑定。
- 抽屉没有额外的“终端”标题，标签显示实际 Shell 可执行名称加递增编号，例如 zsh1、bash2。编号从 1 开始，关闭不复用，应用重启后重置。
- 每个终端在上下文终端分组中显示，选择定位到对应终端；全部关闭后隐藏分组。顶部按钮右上角显示数量，零个时隐藏。
- 标签关闭表示终止 PTY 及其运行中的子命令，并移除上下文条目；收起抽屉或关闭任务页仅隐藏视图，不停止进程。
- 支持拖动高度及最大化/还原；切换标签不重建进程，不清空输出。
- Shell 正常退出保留输出与条目，用户显式关闭后移除；错误不影响其他终端。应用退出结束所有进程，不跨重启自动恢复 Shell 或输出。

## 3. 验收标准

- 实际 Shell 名称、递增编号、角标与上下文条目一致。
- 普通终端使用任务工作目录，不依赖 Agent hooks；目录不存在时报错，不回退到用户目录。
- 运行命令时关闭终端能停止进程树，其他终端不受影响。
- 任务侧栏小尺寸、独立标签和双页拆分均可操作；折叠、隐藏和切换页面不会重复启动。
