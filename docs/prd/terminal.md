# 终端工作区（保留能力）

[产品需求索引](../../PRD.md)

## 1. 当前边界

保留终端渲染、独立 Shell 会话管理及主进程 PTY 能力。当前新版顶部不展示旧审查和终端 tab，也不新增终端入口；后续任务详情需要终端时再定义入口与生命周期。

保留终端组件、VT 渲染、独立 Shell 和 PTY 服务；后续接入时沿用独立块、主题色和布局边界，不重新引入旧会话列表。

## 2. 状态与交互

以下为保留的终端组件行为，当前一级导航不提供终端入口：

1. 终端启动失败时，在终端区域展示错误状态，不自动销毁实例。
2. Shell 主动退出后保留最后一屏内容并展示退出状态，等待调用方关闭实例。
3. 单个终端失败或退出不能影响其他终端、任务面板和详情区域。

覆盖启动中、运行中、已退出、启动失败四种状态。新任务中的终端创建、关闭和关联规则待后续确认。

## 3. 验收标准

- 当前导航和顶部不出现旧终端 tab 或新增终端按钮。
- 保留的终端能力不依赖外部 Agent hooks。
- 启动失败、退出状态可辨识，失败实例不自动清空已有输出，不影响其他模块。
