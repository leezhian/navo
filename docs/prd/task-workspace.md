# 任务工作台

[产品需求索引](../../PRD.md) · [Tasks](tasks.md) · [终端](terminal.md)

## 1. 范围

任务侧栏与任务标签使用相同的工作台。提供原生 CLI 会话、普通 Shell、资源导航、分支/变更面板和现有 Diff 入口；不提供自定义富聊天，不接入外部会话接管。

## 2. 布局与资源

- 顶部显示任务名称、任务状态、任务操作菜单（夹在标题与状态标签之间，不并入右侧按钮组）、上下文显隐与终端显隐；任务标签页只通过标签上的关闭按钮关闭，页面内部不重复提供关闭。Tasks 侧栏保留关闭及提升到标签的入口。任务顶部不提供新建会话按钮；会话面板头部与上下文会话分组均提供加号入口，无会话时主区提供相同的新建入口。不包含 demo 的预览状态、重播和更多菜单。
- 详情内可重命名任务：双击顶部标题、不在输入框时按 F2、或任务操作菜单中的「重命名」，进入就地编辑。规则与列表右键重命名相同（非空、最多 160 字）；Enter 或勾确认，Esc 或 × 取消。编辑态输入框与只读标题字号、字重、行高及左侧起点一致，进入／退出编辑时标题行高度与位置不跳动。不做自动命名。列表右键重命名入口保留。
- 详情任务操作菜单（⋮）提供本任务已有能力，交互与确认流与列表右键及现有弹窗一致，不新造流程。菜单自上而下分四组，组间以分隔线隔开：① 重命名、改状态（TODO／DONE，已归档任务先恢复再改）、标为已读／未读；② 添加资源、关闭全部 Agent（停止本任务全部未归档会话的进程，保留会话记录与面板）、刷新工作区状态（重新探测本任务已关联工作目录的分支与可用性；成功不弹窗，仅刷新分支区；任一仓库失败时提示失败仓库；无仓库时置灰；不伪造远端数据）；③ 复制任务链接、复制任务正文（正文非空时显示）；④ 归档／恢复任务、删除任务（删除置底并保持警示色）。归档任务仍遵循既有归档只读边界；删除与归档清理确认复用现有弹窗。
- “复制任务链接”生成 `navo://task/<任务 ID>` 本机定位链接，不包含正文或工作路径。安装版可从外部应用唤起 Navo，等待任务加载完成后打开对应任务标签；已打开时直接激活原标签，包含拆分页。已归档任务仍可查看；找不到任务时提示并保留当前页面。此链接不提供跨设备分享或任务导入，开发运行不注册系统协议。
- “复制任务正文”直接复制当前已保存正文，保留换行和空白，不附加任务标题或笔记标题；纯空白正文隐藏入口。复制成功时菜单按钮短暂显示勾，失败提供可见提示。
- 任务级已读操作聚合未归档 Agent 会话：存在未读时显示“标为已读”，一次清除该任务全部会话的未读；全部已读时显示“标为未读”，标记最近活跃的一个会话；没有 Agent 会话时隐藏。手动未读在本机持久化，并同步影响会话条目、任务列表／卡片及标签的未读展示；不改变任务状态或进程状态。当前会话保持打开时不立即清除手动未读，再次进入该会话或主动标为已读后清除。
- 左侧按会话、CHANGES、终端、PULL REQUESTS、ISSUES、LINKS、NOTES 分组，可独立折叠；任何分组没有子项时不显示标题、计数或操作入口，新增子项后出现，清空后隐藏。CHANGES 放关联仓库，PR/Issue 分别归组，LINKS 放附件、文件夹和普通链接。NOTES 首项固定展示任务正文（Prompt），其后为普通笔记；计数包含正文，因此始终保留分组；LINKS 同时收纳按原路径引用的文件。
- 会话条目显示对应 Agent 的品牌图标、CLI 的真实会话名称及文字状态，不以状态图标替代 Agent 图标。名称过长单行省略，悬停显示完整名称；进程四态以状态文字区分，运行和失败辅以颜色。有运行相位／等待原因／未读时在条目或悬停中展示，规则见生命周期。
- 会话面板标题与上下文使用同一个真实名称，不再使用“Grok Build 1”等自动编号名称。只按精确原生会话标识读取 CLI 标题元数据，按第 4 节的触发规则同步并保存本地快照；读取失败保留上次真实名称，没有名称时显示“未命名会话”。当前读取 Grok 的生成标题、Claude 的用户改名或生成标题；Codex/Antigravity 在精确绑定原生 ID 后读取该会话的标题，没有映射时保持未命名，不用任务标题或其他最近会话的名称冒充。名称更新不抢焦点、不重启进程。
- 每个活动会话条目首行独立展示名称，次行显示状态与工作目录信息，右侧提供“归档会话”（Archive session）按钮，点击不切换当前会话。归档后从活动列表移除；当前会话被归档时切到其余可用会话，没有活动会话则回到新建会话空态；若仍有归档会话，保留会话分组。
- 活动会话条目右击提供 Open、Rename session、New session from this one、Archive session、Delete session，随语言切换；重命名、归档、删除带前置图标，删除保持警示色。右击不切换当前会话，Open 始终展示所选会话，重复打开不收起。重命名和删除复用会话操作下拉的能力限制及确认弹窗，取消或关闭上层弹窗不关闭上下文面板。
- 已归档会话条目右击仅提供 Restore、New session from this one、Delete session。恢复沿用条目原有恢复及选择行为；从此会话新建使用相同的 Agent 子菜单与目录规则，原会话保持归档，不先恢复或启动它。删除沿用原生会话能力限制和二次确认。任务本身已归档时禁用恢复与新建。
- 会话面板不额外展示模型、模式、思考等级及“运行中”等状态文案；上下文仍显示会话状态，原生 CLI 自己输出的内容保持不变。面板头部保留名称、新建会话加号、会话操作下拉和关闭面板按钮，不再提供中止按钮；停止或失败后只显示“恢复对话”，不重复展示“重启 Agent”。无法识别可恢复原生对话时禁用恢复并说明原因，实际异常不能被静默隐藏。
- 任务状态紧邻顶部任务标题，长标题省略但保留状态展示。任务上下文不重复显示标题，顶部“添加资源”（Add resource）打开统一资源窗口。
- 每个可见分类标题右侧均有加号：会话、终端保留现有创建行为；CHANGES、PULL REQUESTS、ISSUES、LINKS、NOTES 打开同一资源窗口，并分别定位仓库与文件夹、PR、Issue、链接、笔记页。空分类继续隐藏，首次添加通过顶部入口进入。
- “关闭面板”（Close pane）移除会话内容模块，不停止进程、不归档或删除会话；从任务上下文点击不同会话时切换并展示，重复点击当前会话则切换面板显隐，不重复交付指令。终端条目遵循同样规则，面板隐藏时取消对应条目高亮；会话被最大化终端遮住时，点击会话恢复展示。普通终端仍独立展示，主会话面板关闭后可占用剩余空间。终端收起使用底部面板收起图标，与会话菜单的下拉箭头区分，收起不会终止进程。
- 会话面板标题旁展示对应 Agent 小图标，随当前会话切换；保留原有状态图标，不显示重复 Agent 名称。
- 会话操作下拉分三组：Rename session；Restart Agent、Shut down agent；Archive session、Delete session。Restart Agent 仅在启动中或运行中显示；停止或失败后从面板恢复对话。重启先停止旧进程，再使用已识别的原生会话 ID 重连同一对话，保留名称、工作目录与 Agent 配置，不再次发送首条任务指令。重启重新检查当前 CLI 并读取登录 Shell 环境，可用于加载更新后的 CLI；无法可靠识别原对话时禁用重启，不创建新对话作为替代。关闭 Agent 结束进程树但保留记录、历史输出及面板，已停止或失败时禁用。操作期间禁用重复提交，不影响其他会话。重命名/删除同步到 CLI 原生记录，不是仅修改 Navo 标签；当前仅对能精确识别的 Claude/Grok 开放，其他 CLI 保留禁用项和说明，不伪造成功。
- CHANGES 中的仓库打开其实际工作目录的分支栏，不再直接弹出 Diff；PR/Issue 预览已有的标题、来源、仓库和状态，不伪造远端正文。普通链接使用系统浏览器打开 HTTP(S) 地址，附件在文件系统中定位应用管理的副本。
- CHANGES 与 NOTES 的选中状态跟随右侧实际显示内容：分支栏展示哪个工作区，就高亮对应 CHANGES；笔记打开时仅高亮对应 NOTES。收起右侧区域或被最大化终端隐藏时取消高亮，再次展示时恢复，不与会话选中状态互相影响。
- CHANGES 右键使用统一菜单，依次提供打开、打开方式、在此新建会话、在此新建终端、在此运行命令、复制分支名、复制 Worktree 路径、复制远程 URL、解除关联和删除 Worktree。打开只展示所选工作区的分支栏；新建会话通过 Agent 子菜单选择，沿用真实能力缓存与默认配置；会话、终端和命令均绑定所选工作目录。打开方式及命令子菜单与快捷入口共用选项、图标、缓存和运行／停止规则，不在右击时重新扫描；没有命令时仍可展开命令子菜单，展示不可点击的“暂无命令”（No command yet）和可用的“管理命令…”入口。复制分支名使用条目当前展示名称，路径使用实际工作目录，远程地址保留 SSH/HTTPS 格式并去掉凭证，无远端时禁用复制。
- 仅 Worktree 条目展示“删除 Worktree”，原仓库及直接使用分支的目录不展示该菜单项。删除仅对 Navo 创建且归属可核实的 Worktree 开放，未知归属时禁用。操作需二次确认，展示目录及未提交、未跟踪、忽略文件风险，默认焦点在取消。保留任务和 Git 分支，成功后解除该工作区关联并更新共享视图；最后一个 Worktree 也可通过此明确的物理删除操作清理。被会话、终端、初始化或其他任务占用时拒绝；外部锁、目录替换及确认后内容变化必须重新处理，失败保留任务与清理进度供再次确认。归档任务禁止新建、命令、解除关联及删除，仍可打开和复制。
- CHANGES 条目使用 Git 分支图标，首行直接展示分支名称，不再展示仓库名称或重复的分支描述；优先目标分支，没有则使用源分支。次行右侧保留打开方式组合按钮和独立的命令入口。打开方式左侧按钮显示并执行全局上次成功选择的方式，图标及提示同步变化；首次使用默认为文件管理器。偏好保存在本机设置中，重启保留；未安装的编辑器、不可用的外部终端或缺失远端临时回退文件管理器，失败的打开不改变偏好。右侧下拉顶部列出本机已安装的受支持 IDE，图标按编辑器标识映射常用品牌的静态 SVG，与托管平台图标使用相同方式；未覆盖的编辑器使用通用图标，不读取、转换系统图标或请求远程图片。通过分割线与下方的文件管理器、外部终端及远端仓库页面分组，无 IDE 时不显示分割线。按钮与分支栏主区域独立，点击按钮不触发分支栏或 Diff。菜单不展示读取失败或未检测到 IDE 等提示；读取失败保留已有选项，不清空或闪烁。
- 命令快捷入口位于打开方式右侧，采用“运行／停止按钮 + 下拉箭头”的组合。无运行命令时，主按钮优先使用当前工作区最近命令记录对应且仍在配置中的命令，否则使用配置首条；有运行命令时主按钮停止最近启动的一条，启动中显示转圈。主按钮提示包含具体命令名和工作区范围，例如英文 `Run "install" in this worktree`，停止提示同步变化。下拉箭头仅展开菜单，列出该仓库已保存的命令，顺序与配置一致；选择后在当前工作区的独立终端运行，展开输出但不抢输入焦点。运行中的菜单项显示停止图标，重复选择执行停止并关闭对应命令终端，不启动第二份相同命令；即使命令配置被删除，仍保留其运行项供停止。同一仓库的不同 Worktree 可分别运行。既无已配置命令也无运行命令时，隐藏整组快捷按钮和下拉箭头，不保留占位；首次添加命令可从右键“在此运行命令 → 管理命令…”或设置中的仓库编辑入口进行。有命令时菜单提供“管理命令…”，复用该仓库的编辑弹窗，可添加、编辑、删除命令，保存配置不执行脚本。归档任务不提供运行入口；工作目录和仓库归属由主进程重新核对。
- 外部终端在 macOS 使用 Terminal，并以该 Worktree 的实际目录启动，不新增任务内终端，不运行资源配置中的脚本。IDE 同样打开实际工作目录，不使用原仓库路径替代 Worktree；当前提供 macOS 应用检测，其他平台不伪造 IDE/外部终端可用状态。
- 远端读取本地 Git 配置，优先 origin，否则首个远端；支持 SSH/HTTPS 转换网页链接，去掉认证信息。菜单名称和品牌图标匹配实际识别的平台，支持 GitHub、GitLab、Bitbucket、Gitee；无法可靠识别的自托管地址显示主机名与通用网页图标，不冒充平台。无可用网页远端时隐藏该项；点击时重新核对远端，不执行 fetch 或联网探测。
- IDE 检测为已知编辑器目录，覆盖 VS Code、Xcode、Cursor、Windsurf、JetBrains 系列、Zed 等；只有实际发现并校验应用 Bundle ID 后才显示，不为检测启动 IDE。编辑器安装列表采用全应用共享的 30 分钟内存缓存，图标为内置静态映射；并发检测合并，失败保留结果并至少间隔 1 分钟再尝试。实际打开某编辑器时只复核该应用，不重扫全部编辑器；安装失效时清除缓存有效期并后台更新菜单。
- 打开方式在首次进入工作台时预读，后续进入工作台或应用回到前台时才检查过期缓存。各工作区菜单快照共享 5 分钟内存缓存；本地 Git 配置和编辑器检测分别复用各自缓存，未到 30 分钟不重扫编辑器。下拉展开只展示已有快照，不触发查询；失败保留上次结果且重试至少间隔 1 分钟。工作目录变更使用新的缓存条目，不串用旧目录结果；不写入 SQLite、不设置定时轮询。
- 主区展示当前 Agent CLI，下方为独立普通终端块。上下文宽度和终端高度可用 8px 分隔条拖动或方向键调整，终端可最大化及收起。
- 多工作目录时，顶部终端入口提供目录下拉菜单，终端面板和上下文终端分组的加号共用相同选择规则；选择分支／仓库或文件夹后，在该资源的实际工作目录新建并展示终端。单目录直接创建，无目录使用任务目录；详细规则见任务内终端页面。
- 顶部右侧终端入口位于分支栏切换按钮左侧；分支栏按钮按实际显隐状态提示“显示分支栏”或“收起分支栏”。任务上下文与分支栏切换按钮采用对应方向的面板展开／收起图标，与终端面板的向下收起图标保持同一风格。
- 响应实际容器宽度，而非只看窗口宽度。小于 620px 时上下文默认收起，打开后以工作台内部的侧滑面板显示，保留圆角和局部遮罩，不挤压 CLI、不遮挡或锁定其他任务区域；支持侧滑淡入淡出，减少动态效果时取消动画，Esc 或点击局部遮罩关闭。关闭后焦点返回上下文入口，但不抢占已打开的资源弹窗焦点；子菜单和资源弹窗关闭不连带关闭上下文。宽屏保留可拖动宽度的常驻分栏。适用于 Tasks 右侧栏和双页拆分。标题省略，操作区可换行，240px 宽时不得溢出。
- 布局记忆按任务保存在本机：上下文栏宽度、分支／笔记栏宽度、终端高度，以及上下文、分支栏、终端的显隐（含终端是否最大化）。再次打开同一任务、工作台重挂载和应用重启后恢复；无记录时沿用现有默认（窄屏上下文默认收起等）。不记忆选中的会话／笔记／工作区，也不记忆弹窗与草稿。会话与终端进程不依赖这些布局状态。
- 任务工作台支持下列页面快捷键（修饰键按系统显示；焦点在输入框、原生终端或对话框内时不抢占其默认行为）：F2 重命名当前任务；⌘/Ctrl+B 显隐上下文；⌘/Ctrl+J 显隐终端；⌘/Ctrl+Shift+J 最大化终端（若已收起则先展开再最大化）。分隔条聚焦后仍可用方向键调整宽度或高度。设置 → 通用 → 快捷键区同步列出上述已支持项，不提供自定义绑定。

### 2.1 添加资源
- 统一弹窗左侧为仓库与文件夹、Issues、Pull requests、Notes、Links、Files；顶部入口默认定位仓库页，CHANGES 加号直接进入该页。仓库页复用创建任务的工作目录选择界面：搜索、多选及快捷添加。已关联仓库仍可选择，按情况显示“仓库已添加”或“仓库和分支已添加”；已关联普通文件夹禁选。勾选仓库后右侧展示隔离 Worktree 和源分支，无目标分支输入。新增全局仓库后自动勾选，普通文件夹只关联路径。
- 确认后在当前任务追加实际工作目录。隔离模式创建独立 Worktree；关闭隔离后基于源分支在原仓库新建分支，要求工作区干净；“使用当前分支”不切换分支、不创建 Worktree。目标分支按“设置前缀 + navo-task- + 八位随机十六进制字符”生成，不覆盖已有分支。新增 Worktree 与创建任务使用相同的平铺规则，直接存放在设置目录下，以“项目名-分支随机八位”命名；使用已有分支且需要新建工作区时另取随机八位，不增加任务或批次目录，不搬迁已有工作区。默认设置 Git 锁，沿用创建任务的锁定与安全清理规则，复用已有工作区不改变其锁定状态。
- 同一任务可关联同一仓库的多个不同工作区，各有独立且稳定的任务内标识；CHANGES、会话、终端、外部打开、Diff 及删除按该标识定位，不再将仓库标识等同于工作区。旧任务与会话保留原绑定。主进程重新探测目录及分支，以真实工作目录去重，符号链接或路径别名不形成重复条目；选择已有分支时复用对应工作区，重复绑定不新增条目。新建独立分支/Worktree 则新增条目，不因仓库相同而拒绝。
- 追加资源及托管目录归属原子保存，同一提交重试不重复创建；失败只回滚本次可确认安全的新增内容，保留用户修改的现场并提示，不清理原有任务工作目录。中断后的安全回滚沿用任务创建恢复规则；归档任务和进行删除清理的任务不允许新增工作目录。复用的外部 Worktree 不取得删除归属；基于原有分支创建的 Worktree 可按规则清理目录，但不会删除原有分支。
- 追加成功立即更新 CHANGES、普通文件夹所在 LINKS 和新会话/终端的目录选项；现有会话及终端保持各自工作目录和范围，不自动重启或注入新指令。后续新会话以最新资源构建上下文；任务首次关联工作目录时同步项目名，已有项目名、标题、描述及状态不被覆盖。新增托管 Worktree 可在后续删除任务时按相同安全规则清理。
- Issue/PR 共用创建任务时的列表、搜索、服务商/仓库/任务关联过滤及可调宽度预览，PR 另有状态过滤。默认只显示尚未关联任务的条目；当前任务已绑定条目不可再次选择。不伪造远程条目或拉取能力。
- Links 共用创建任务时的 URL 和标题表单：HTTP(S) 链接必填、标题选填，校验与描述一致。Files 每次选择一个磁盘文件，展示文件名及原路径，确认后按规范路径绑定；不复制、不改写文件。文件移动或删除后定位失败，不切换到其他路径。
- Notes 标题选填（最多 160 字符）、Markdown 正文必填（最多 100000 字符）；保存原文，空标题显示未命名笔记。支持查看、编辑和删除；接入任务 MCP 的 Agent 可在当前任务内新增、读取、修改和删除普通笔记，不提供富文本渲染。
- 每条笔记保存独立版本、创建来源（用户或 Agent）、创建会话、排序值、创建和更新时间。版本从 1 开始，标题、正文或顺序实际变化才递增，并同步递增任务上下文版本；无变化保存不刷新时间。后续编辑保留原创建来源与时间。笔记默认追加到末尾，按排序值展示，相同值保持插入顺序；本阶段不新增界面拖拽排序入口。旧笔记保留原顺序，时间沿用任务已有记录，升级不制造新活动；不保存完整历史版本。
- 编辑及删除必须提交读到的笔记版本。编辑锁定开始编辑时的版本；删除锁定打开确认时的版本。与其他视图或 Agent 的修改冲突时拒绝覆盖或删除，保留草稿并提示重新读取；即使内容修改后又恢复原文，旧版本仍失效。笔记在编辑期间被删除时保留未提交草稿，保存明确报错。
- “添加到任务”保存当前类别后关闭；“添加并继续”保存后保留窗口，清空已提交类别草稿。切换类别保留其他未提交草稿；取消丢弃未提交内容并释放文件选择令牌，不影响已经成功绑定的资源。
- 添加直接持久化到当前任务，保存成功即时更新侧栏、任务标签和其他共享视图；不新建任务、不改变状态、不启动或重启 Agent。原有资源保留，重复 Issue/PR、相同规范 URL 和原文件路径不重复绑定；同一提交重试不重复创建笔记。
- 操作失败保留输入及选择并显示错误；保存或系统文件选择期间阻止冲突操作。系统文件选择令牌按窗口隔离，不能提交任意磁盘路径。
- 笔记的新增、修改、删除和文件引用随之后启动的新会话或新对话进入任务上下文；已连接任务级 MCP 的 CLI 可按需读取最新内容；不强制刷新模型当前上下文、不打断进程。删除任务只删除引用和笔记记录，绝不删除外部原文件。

### 2.2 分支栏与完整 Diff

- 仅 Git 仓库提供分支栏，普通文件夹不显示该入口。宽工作台默认展示首个关联仓库；CHANGES 点击不同仓库切换数据，顶部按钮可收起/展开。会话和分支栏并排，终端仍位于两者下方；拖动 8px 分隔条调整宽度。
- 分支标题读取实际工作目录的当前分支，detached HEAD 显示短提交标识；不把创建任务时的旧分支名冒充当前状态。仓库查询只允许当前任务已关联的目录。
- 工作区分别展示未暂存、已暂存文件，支持文件筛选、文件树/平铺列表及目录展开收起；文件数按路径去重，增删统计按两个差异层累计。与原有完整 Diff 一致，仅列出已跟踪变更，另行提示未跟踪文件数量，不把它们伪装为空改动。
- 提交页展示相对任务源分支的真实提交列表及分支整体文件差异；最多展示最近 100 条并标明截断，不假装为提交总数。无有效源分支、无共同基点或尚无提交时说明原因，仍允许查看工作区变更。本期不增加单个 commit 的 Diff 阅读模式。
- 打开完整 Diff 复用现有审查内容，保留文件树、评论、阅读设置、暂存/取消暂存、还原与提交等原有能力，不使用 demo 的简化代码预览。点击文件按完整路径定位，并进入对应未暂存、已暂存或分支对比范围。
- 完整 Diff 以弹窗承载，宽屏四周留 24px，小屏留 8px；顶部使用紧凑的仓库/分支标题及关闭按钮，不预留空白顶部区域。关闭后回到原任务，不关闭会话或终端。分支栏带入的源分支只作用于本次 Diff，不覆盖全局默认目标分支。
- 可见时监听工作目录/Git 变化并定期检查，后台刷新保留已有列表；同一视图的连续请求合并，切仓库后丢弃旧响应。查询失败提示重试，不能静默展示演示数据；隐藏分支栏时释放其监听。
- 空间不足时，分支栏与上下文共用局部侧滑面板：上下文从左侧展开，分支栏从右侧展开，统一圆角、局部遮罩、侧滑淡入淡出及减少动态效果规则，不挤压会话、不锁定其他任务。两者互斥展开，支持 Esc、局部遮罩和原有按钮关闭，关闭后恢复对应入口焦点；关闭子菜单或完整 Diff 不连带关闭底层面板，也不抢占上层弹窗焦点。宽屏仍保留可拖动的独立分栏。小屏默认不自动打开，用户可从 CHANGES 或顶部按钮唤起。

### 2.3 笔记预览与维护

- 点击 NOTES 条目，在右侧预览笔记标题及 Markdown 原文，与分支栏共用同一个位置，互斥切换，不额外增加一列或打开通用预览弹窗。宽屏可通过 8px 分隔条调整宽度；窄空间使用工作台内的右侧抽屉，不挤压 CLI，并与窄屏上下文抽屉互斥。
- 笔记头部提供复制、编辑、删除和关闭。复制包含标题、一个空行和完整 Markdown 原文，空标题使用未命名笔记文案；编辑中复制当前草稿，成功后复制图标变为勾，约 2 秒后恢复，失败提示并允许重试。编辑在面板内进行，支持修改标题和正文、保存及取消；宽窄布局切换保留草稿。保存成功同步所有使用该任务的视图，失败保留输入并提示。归档任务可查看、复制笔记；任务正在删除时拒绝写入。
- NOTES 条目右击使用项目统一的右键菜单，包含打开（Open）、复制笔记（Copy note）、删除（Delete）；任务正文也支持打开与复制，不提供删除。右键复制使用已保存的标题和完整正文，不切换预览或影响草稿。删除保持警示色并复用二次确认。右击本身不改变选中项；打开遵循已有面板切换及草稿保护规则，删除未显示的笔记不关闭当前面板，也不丢弃另一条笔记的编辑草稿。
- 存在未保存修改时，切换其他笔记或分支、关闭笔记面板、取消编辑，以及使用任务侧栏自身的关闭或提升标签入口，均先确认是否放弃；取消确认保留当前面板与草稿。窄屏 Esc 和遮罩关闭遵循同样规则，关闭上层确认框不连带关闭底层抽屉。该保护不扩展为全局标签关闭或应用退出拦截。
- 删除需要二次确认，默认焦点在取消，明确不可撤销且会丢弃被删除笔记的未保存修改。确认成功后只移除目标笔记；目标是当前预览时关闭右侧面板，否则保持当前面板与草稿，其他笔记、资源与会话不受影响。最后一条普通笔记删除后仍保留固定的任务正文入口；失败保留笔记及确认框供重试。
- 普通笔记变更不修改任务正文；成功保存后更新任务时间及上下文版本，供已连接的 Agent 按需读取。保存时检查原始内容，其他视图已经修改时提示冲突并保留草稿。

### 2.4 任务正文与解除关联

- NOTES 首项为任务正文（英文 Prompt），读取任务原始描述，始终存在，不允许改名或删除。旧任务描述为空时可直接编辑；正文保存要求非空，最多 100000 字符。
- 正文使用与笔记相同的右侧预览、编辑、取消、未保存确认与归档只读规则。保存成功同步任务各视图，保留任务标题和分支名，不改写已有对话消息；并发冲突保留草稿并提示重新读取。
- 工作区、Issue/PR、链接、附件和原文件条目右击提供解除关联，需二次确认。只移除任务绑定，不删除外部文件、Git 分支、Worktree、锁或远端条目；应用附件副本随任务清理。
- 任务只剩一个工作目录时禁用解除关联，计数包含仓库和普通文件夹；主进程保存前再次检查，避免并发操作移除最后一个目录。该限制不影响其他类型资源的解除关联。
- 工作区仍被运行会话、全任务会话、终端或初始化占用时拒绝解除关联，提示先停止。解除后旧会话历史保留，但绑定该工作区的旧会话不能继续启动；已解除的工作区不再纳入任务删除清理范围。归档或删除中的任务拒绝内容修改。

### 2.5 可选会话轨迹

- 在实验室单独安装并启用会话轨迹后，Claude Code、Codex、Grok、Antigravity 会话面板标题栏右侧提供「终端 / 轨迹」图标切换（不额外占用一行），默认进入终端。未安装、关闭及不支持的 Agent 保持原有界面。
- 轨迹界面由 Navo 直接渲染，搜索框、筛选、按钮和提示使用项目统一组件，风格与任务工作台一致；解析在插件进程内完成。搜索框有内容时，右侧提供清空按钮，使用与搜索图标相同的次要文字色，并带有名称提示。
- 轨迹只读展示当前会话对应的原生历史，停止的会话也可查看。原生身份尚未绑定、无法定位日志目录、文件不存在、记录不匹配和解析失败分别给出明确提示，可重试，不能停留在加载中；不选择最近记录冒充当前会话。
- 各 Agent 只读取已绑定原生会话对应的日志，不扫描其他会话：
  - Claude Code、Codex 沿用现有绑定路径。
  - Antigravity 读取 `~/.gemini/antigravity-cli/brain/<id>/.system_generated/logs/transcript_full.jsonl`（与 `transcript.jsonl` 条数一致，内容更全）。每条有 `created_at` 和递增的 `step_index`；工具调用没有 id，按出现顺序与紧随其后的结果配对。`status` 为 ERROR 时只记一条错误（优先使用 error 字段，没有则记该条的第一条可见内容），同条里的思考和回复仍按原类型展示，不重复计入错误数；工具结果失败只标该条结果。
  - Grok 正文读取 `~/.grok/sessions/<cwd>/<id>/chat_history.jsonl`，时间与耗时先从同目录 `events.jsonl` 按 `tool_call_id` 和轮次起止补全，仍缺的再用同目录 `updates.jsonl` 中能按消息精确对应的时间补全；对不上的保持无时间，不按顺序或相邻记录推测。`events.jsonl` 仅较新版本才会完整写入，老会话可能只有部分轮次有时间。`chat_history.jsonl` 以整文件替换而非追加，文件被替换后重建索引，不能按偏移追加。
- 提供紧凑统计、输入/模型/工具时间线、类型筛选、全文搜索和虚拟滚动列表。列表不翻页，只渲染可视范围内的行；事件摘要由解析进程按滚动窗口分段返回，正文仍在选中后按需读取。首次打开先取最新一段并停在最新事件，列表上方按未加载条数预留滚动空间，往上滚动时再取更早的窗口。解析仍从头建立完整索引（轮次与工具调用配对依赖前文状态），首次建好后缓存；追加型日志只追加新内容，整文件替换的日志在被替换后重建索引。统计基于完整索引，时间线只包含有时间戳的事件。按用户轮次及可确认的模型请求分组；缺少请求边界、时间或耗时时显示「未记录」，不写成 0，也不因此隐藏该行。时间线只绘制有时间的事件；整段无时间以时间线中没有任何带时间的事件为准。日志中的空行跳过，不显示为未知记录。
- 顶部统计只显示轮次、请求、工具和错误数，不显示会话总时长和 Token 用量；时间线不显示时间刻度和轴两端的起止时间（原 0s/中点/总时长整行去掉），保留事件块与输入/模型/工具分道；压缩和未知有时间时画在输入道，避免等宽记录空出一格。默认按记录等宽铺满：每条有时间的事件占同样一格，事件之间的空等不占宽度。统计行右侧提供「时长」开关，不记住选择，离开该会话后恢复默认等宽。打开后按实际耗时排列并去掉空等。切换时清除当前缩放和框选。横轴不展示时间。用浅色竖线标出每个用户轮次的开始：等宽记录时竖线落在该轮第一条记录上；打开时长后，竖线落在该轮最早时刻在压缩后时间轴上的位置。竖线只作视觉参考：不带文字、没有悬停提示、不响应点击，也不挡住下方事件块的悬停、点击和框选；轮次没有任何带时间的事件时不画线；相邻竖线间距小于 4px 时只画一条。竖线框选时不置灰。不读取、不统计 Token 用量（包括 Grok 的 `usage.json`）；列表右侧仍显示单个事件的时间与耗时。时间线方块悬停只显示类型、开始到结束的时刻（时:分:秒.毫秒）和总毫秒数，不显示工具名或摘要；没有耗时时不补 0，总耗时显示「未记录」。右侧详情面板不展示时间和耗时。
- 没有时间戳的事件只进入列表，不进入时间线，也不作为框选依据、不计入选区命中。框选生效时，这些列表行按选区外置灰，第一次点击只取消框选。已对上时间的事件照常进入时间线和框选。整段会话都没有时间时，隐藏时间线并提示「该会话未记录时间，无法使用时间线和框选」，列表仍全部展示；只有部分事件有时间时，时间线只绘制这些事件，不另做空状态。
- 事件按类型展示用户、助手、推理、系统/上下文、工具及结果、错误、压缩和未知记录。详情统一在右侧面板打开，查看正文、参数、结果或原始 JSON；列表行不再展开，也不再提供侧栏切换。未选中事件时右侧详情整栏不展示，列表占满宽度；再次选中时按上次分隔比例打开详情。在列表或时间线上再次点击当前选中的事件，取消选中并收起详情。列表与详情之间提供可拖动分隔，拖动手势放在分割线上，不单独占一列，避免和边框错位；复用工作台现有分栏拖动手势，两侧设最小宽度；分隔比例在当前会话面板内保留，终端与轨迹来回切换仍有效。面板较窄、上下排列时不支持调整高度。大段正文明确标注截断，不能执行日志中的 HTML 或命令。
- 原生日志中的附件按内容归类：文件、会话上下文、环境、prompt 快照归入上下文；`total_tokens_reminder` 及其余 Token 记账记录（如 `token_usage_record`、`token_count`）按记账默认隐藏，不进入时间线、不做统计，可通过「显示全部」查看原文。模式、权限模式及线程设置仅在值实际变化时记一条系统记录。`queue-operation` 归入系统。`custom-title` 按记账默认隐藏，不出现在默认时间线，可通过「显示全部」查看。其余纯记账记录（如 last-prompt、重复快照）默认不出现在时间线，但不得丢弃，可通过「显示全部」查看原文。仍无法识别的记录保留为未知，原文照常展示。
- 点击时间线定位对应事件并展开。首次打开、类型筛选或搜索变化后，列表停在最新一条匹配结果；当前选中的事件仍在结果中时停在该事件；框选后滚到仍在当前筛选和搜索结果里、按记录顺序的第一条命中。这些命中都不在当前结果里时不滚动，也不改已加载的列表窗口。默认保留阅读位置，可主动开启跟随新事件；新增数据更新列表与统计，未完成尾行在完整写入后显示。
- 时间线支持选择与框选（参考 DeepSeek Harness 轨迹概览）：
  - 选择：点击时间线上的事件块，定位该事件并在右侧打开详情；选中块略微加高，使用与事件类型相同的 1px 细描边，不再使用粗描边；点击选中不把其他块置灰。列表对应行加底色、不显示展开箭头。在列表或详情中选中事件时，时间线同步高亮；已经放大且该事件不在当前时间窗内时，只平移时间窗使其进入，不改变缩放倍数。取消选中后右侧详情整栏收起。
  - 框选：在时间线上按住拖动（移动超过 3px 才算拖动，否则按点击处理）框出一段时间，松开后列表不收窄，仍显示类型筛选、搜索和「显示全部」之后的全部结果；与选区有重叠的事件正常显示，其余置灰，时间线上选区外的块同样置灰；命中按当前投影判断：事件在投影里的区间与选区重叠即命中，等宽记录按槽位而不是墙上时间，所以更早开始、但排在前面的长工具不会因为持续时间跨进后面的槽位而被算进选区。列表滚到仍在当前类型筛选和搜索结果里、按记录顺序的第一条命中。选区没有命中任何事件时列表全部置灰，且不滚动。命中都被当前筛选或搜索排除时，不滚动，也不替换已经加载的列表窗口。拖动过程中实时显示选区，选区太窄时按一个事件的最小宽度处理。
  - 已框选时，时间线上保留选区高亮；筛选栏不显示时间段、条数或清除按钮。按 Esc、双击时间线或在时间线空白处单击取消框选，恢复正常显示。已框选时第一次点击选区外（置灰）的列表行或时间线块，只取消框选，不打开该事件、不改变当前选中；点击选区内的事件仍定位并在右侧打开详情。当前选中的事件在选区外时保留选中和详情，仅该行置灰。
  - 选区内没有事件时不单独提示，列表全部置灰，不自动扩大选区。「没有匹配的轨迹事件」只在类型筛选或搜索把结果全部滤掉时出现。
  - 框选只在当前面板内生效，切换会话或关闭面板后清除；终端与轨迹来回切换保留选区。开启跟随新事件时，新事件照常追加，选区外的置灰。没有时间戳的事件不进入时间线、不参与框选命中；框选生效时列表中这些行视为不在选区内，置灰显示。
  - 时间线鼠标指针在可框选区域显示为十字光标，右键平移时为抓取光标。键盘可通过 Tab 聚焦时间线。Esc、双击和单击空白只取消框选，不恢复缩放。
  - 滚轮、触控板双指上下滑动和双指张开都缩放当前投影的可见范围，以指针位置为锚；等宽记录最多放大到四格，按时间的投影最多放大到 20 毫秒，整段更短时不再放大，向外放到接近整段时恢复铺满。未放大时仍铺满整段。已放大时可以左右移动窗口：按住右键拖动，或在触控板上左右滑动；右键移动不足 3px 不算拖动，松开后取消框选。放大后框选拖到轴线左右边缘时，窗口跟着移动，选区按当前投影的坐标计算，可以宽于当前窗口。缩放不收窄列表，也不代替框选。新事件只把整段往后延长时，已放大的窗口保持不动。筛选、搜索或「显示全部」使窗口与现有事件不再相交时恢复铺满；切换时长时清除缩放和框选。终端与轨迹切换保留缩放和时长开关，切换会话或关闭面板后清除。
- 查看轨迹不启动或恢复 Agent；切换视图保留已有 PTY，运行中的 Agent 继续执行。关闭插件后回到终端，但这次回退不触发自动恢复；手动恢复与主动选择终端仍按现有规则执行。
- 首次打开轨迹后开始读取；同一会话面板内终端与轨迹来回切换不重新加载、不报错，保留阅读位置。同一原生会话的多视图共享解析。关闭会话面板、隐藏任务、关闭插件、切换会话和退出应用时停止读取。
- 此入口不引入聊天输入、外部会话接管、全机历史浏览或归档会话的新操作；原有归档恢复规则不变。

## 3. 创建与运行

- 创建任务先完成分支/Worktree、附件及 SQLite 保存，随后顺序执行新 Worktree 初始化命令；全部成功后独立启动所选 Agent 的第一个 CLI 会话。没有 Agent 配置的任务不启动进程，提供新建会话入口。重试同一任务创建不会重复启动初始会话。
- 任务成功而会话失败时保留任务及失败会话，不撤销任务或工作目录。任务工作台内新建会话通过工作目录与 Agent 下拉菜单选择后直接创建；不打开配置弹窗。主进程从该 Agent 的真实能力缓存解析默认模型、默认模式与默认思考等级，不沿用任务或上个会话的自定义选项，不填入静态预设；没有可用缓存时禁用对应选项。创建任务弹窗本身的 Agent 配置交互不受影响。
- “从此会话新建”（New session from this one）以子菜单列出与现有新建入口相同的可用 Agent，展开不重新检测。选择后在原会话的工作目录新建并展示独立会话，使用当前任务上下文与所选 Agent 默认配置，不复制聊天记录、原生会话 ID 或旧模型选项，不停止原会话。全任务范围仍保留原任务目录，目录设置变化不迁移它；来源目录无法确认、已解除关联或不可用时禁止创建且不回退其他目录，归档任务禁止创建。
- 没有或只有一个关联目录时，新建菜单直接展示 Agent；一个目录默认绑定该目录，没有目录使用任务专属目录。多个关联目录时，先展示“所有工作树和文件夹”（All worktrees and folders）及各分支/文件夹，再通过二级菜单选择 Agent。分支行展示分支名与仓库名，普通文件夹展示名称；两个新建入口及空态入口规则一致。
- “所有工作树和文件夹”在设置中任务目录下的任务专属目录运行，通过任务上下文了解全部关联目录，并非同时切换所有 Git 分支，也不是文件访问隔离。仅选择单个目录时在该目录启动，任务上下文仍可包含其他关联资源。目录缺失必须报错，不回退其他目录。暂不提供截图参考中的上下文开关、新建其他分支或多账号设置。
- 会话列表补充工作范围：单个仓库显示所绑定目录的分支名，文件夹显示名称，任务目录会话显示“所有工作树和文件夹”。状态与工作范围同一行展示，以“·”分隔；状态完整保留，过长分支或目录名称省略并支持悬停查看。创建时持久化范围标识与名称快照，重启、恢复及失败重试保留原范围；旧记录仅按精确目录匹配，无法确认时显示目录名称，不猜测为全部目录。
- 首条指令通过 CLI 的原生 prompt 参数交付，包括任务描述、仓库路径/分支、PR/Issue 信息和普通链接。多仓库目录写入独占的任务说明文件，不修改关联仓库的规则文件。不注入 hooks，不读取其他会话历史。Claude 与 Codex 不修改全局或仓库配置。Grok 只在本次工作目录的项目 MCP 配置里合并带标记的任务服务，Antigravity 只在应用私有目录写入本次会话的插件配置并用启动参数指向该目录；会话结束时移除。两者都不改用户的 MCP 配置。支持的 CLI 通过当前启动参数或上述会话 MCP 连接任务专属 MCP。
- 所有 CLI 通过 PTY 展示原生界面；权限请求、登录交互和工具确认留在原生 CLI 中，不绕过用户选定的权限模式。启动时重新校验安装、认证及选择兼容性，不把未知认证状态当作未登录。
- 首期支持 Claude Code、Codex、Grok Build、Antigravity；按各 CLI 实际支持的参数应用模型、模式和思考等级。Codex 原生终端当前只接入 default 协作模式，其他模式明确报错，不把 Plan 静默当作 default。缺失参数同样报错，可更新 CLI 或新建其他配置的会话。

### 3.1 Worktree 初始化

- 只对本次新建的 Worktree 执行已勾选“Run on worktree creation”的仓库命令；复用 Worktree、原仓库分支模式和普通文件夹不触发。创建任务与后续增补工作区均适用。
- 命令顺序与保存配置一致，每条使用该 Worktree 的独立命令终端。输出在终端查看，状态和退出码保存在任务内；工作台上下文显示初始化进度。执行计划保存创建时的脚本快照，后续修改设置不影响已有计划。
- 任意命令失败或被停止后停止后续步骤，保留任务、工作目录和执行检查点，禁止启动或恢复 Agent。可手动重试未完成命令，已成功步骤不重复执行；失败或中断的脚本可能已部分执行，重试入口提示这一点。
- 应用退出、窗口关闭或任务删除先停止相关初始化进程；应用重启将未完成计划标为中断，禁止自动重跑。新追加的 Worktree 初始化不重启已有 Agent；重试完成后仅在从未创建过 Agent 会话且任务有 Agent 配置时启动首个会话。

### 3.2 动态共享上下文

- SQLite 是任务上下文唯一事实来源。正文、笔记、关联资源成功修改时递增上下文版本；失败及无变化保存不递增。
- 每个受支持的运行会话使用独立临时凭证连接仅监听本机回环地址的任务 MCP。上下文工具返回最新正文、工作区、资源和含版本、来源及正文字节数的笔记索引；笔记正文不在索引里，按 ID 单独读取。任务整体版本与单条笔记版本分别返回，不能相互替代。
- MCP 提供当前任务普通笔记的新增、修改和删除，创建来源及会话由服务端记录，不能伪造或指定其他任务。修改可更新标题、正文和排序值，省略字段保留；修改与删除必须提供上次读取的笔记版本，冲突返回当前版本及重新读取提示。任务正文、工作区和其他资源仍只读；不能借笔记工具读取任意路径或删除任务正文。归档、删除中的任务及失效凭证拒绝写入，排队操作在提交前再次检查。工具如实标注读写及删除能力，沿用 CLI 自身的工具授权机制。
- Agent 写入与界面保存共用事务规则，成功后即时通知共享任务视图，并更新同任务运行中的文件上下文；失败不发布成功通知。尚未接入任务 MCP 的 Grok/Antigravity 仍通过上下文文件读取，编辑生成文件不会写回笔记。
- Claude Code 通过会话参数、Codex 通过本次进程配置覆盖连接。Grok Build 在帮助文本列出 mcp 子命令时，向本次工作目录的 `.grok/config.toml` 合并一段带标记的任务服务，只记录回环地址和凭证环境变量名，凭证留在本次进程环境中。同一目录的多个 Grok 会话共用这一段，最后一个结束后移除。不改用户级 Grok 配置，也不替换用户的 agent 定义。该文件已有同名服务、帮助里没有 mcp 子命令，或写入失败时，退回会话独立的实时上下文文件。项目配置若是指向该目录内部文件的软链，则改目标文件并保留软链；指向目录外则不写入。
- Antigravity 在帮助文本同时列出 mcp 子命令和 `--add-dir` 时，在应用私有目录为本次会话建立仅所有者可进入的插件目录，写入任务服务的回环地址和凭证，启动参数追加该目录。不修改用户的 MCP 配置，凭证也不进入进程环境。会话结束时删除该目录；应用退出或下次启动会清掉异常退出留下的私有目录。写入失败、帮助里没有 mcp 子命令或没有 `--add-dir` 时，退回实时上下文文件，不标记为已接入。
- 不写仓库规则文件或 hooks，不提供 Chat 会话。MCP 模式不展示上下文说明图标；文件模式保留读取提示操作，旧快照保留提示。文件位于任务目录中。
- 停止、归档会话、删除任务、窗口销毁或应用退出后凭证失效。归档任务不提供上下文读取。运行中的旧会话不热注入，需下次启动或恢复才接入。
- Agent 在调用工具时获得最新数据；不承诺所有 CLI 每轮自动读取，也不改写模型已经使用的历史消息。启动指令提示工作前及上下文可能变化时读取。
- 文件模式在会话启动前写入完整任务上下文；正文、Notes 及关联资源成功保存后，按版本原子更新正在运行的各会话文件。解除关联或删除的条目从完整文件中移除，同任务多个会话共享最新任务数据，各任务之间隔离；文件不作为业务存储读取回数据库。
- 文件模式在启动指令中约定每条新消息或继续工作前重新读取。已接入任务 MCP 的 Grok 或 Antigravity 恢复原会话时不重发任务和读取约定，MCP 仍随本次进程可用。未接入时，Grok 通过原生附加规则参数重新交付读取约定，不重发原任务；CLI 无法传递恢复约定时仍标为快照。Antigravity 可按精确 ID 恢复原对话，但无法通过当前恢复参数重新交付文件读取约定、且没有任务 MCP 时标为快照，不重发原任务。
- 不增加独立消息输入框，不拦截回车，不向 PTY 自动插入提示，不影响输入、粘贴、命令及权限确认。文件内容更新可确认，模型是否每轮读取不能保证，不展示“Agent 已同步”状态。
- 文件模式的现有上下文图标可刷新文件并复制读取提示，用户可粘贴到原 CLI 的对话输入处；复制不会自动发送消息或重新启动。同步失败保留错误提示，可重试；不把写文件失败伪装为内容已更新。
- 会话停止、归档、退出或任务删除后，移除该次运行生成的文件；重新启动或恢复时按 CLI 支持能力准备新的上下文连接。任务归档先停止 Agent 并撤销其 MCP 凭据、清理运行上下文文件；恢复任务不自动启动 Agent。应用异常退出可能留下旧文件，后续启动使用新的独立文件，不复用残留文件。

## 4. 生命周期与恢复

- 会话标识、Agent 配置、工作目录、状态和可用的原生恢复标识保存在 SQLite，开发与正式环境隔离。普通终端与终端输出不写数据库。
- Agent 会话分别持久化最近更新时间与最近活动时间：真实名称、状态、归档等元数据实际变更更新前者，成功启动/恢复以及实际终端输入输出更新后者。高频活动合并保存，结束、归档与应用退出前保存最后活动；不保存输入输出内容。终端输出包含 CLI 自身重绘，不代表已确认的模型思考或用户交互状态。
- 列表读取、附着回放、视图切换和无变化的名称检查不刷新时间；应用重启修正残留运行状态与旧数据回填也不制造新活动。旧会话以创建时间回填活动时间，以已有归档时间或创建时间回填更新时间；会话活动不覆盖任务自身更新时间。
- 会话标题按需读取：进入任务详情或切回该任务标签时，只检查当前任务未归档的会话；新建、恢复或重启会话以及重命名成功后检查对应会话。已有标题不定时轮询，CLI 内改名在下次进入详情时同步。新会话启动时标题尚未生成，则在原生身份绑定、新回复到达或停止时补读；仍不可用时显示“未命名会话”，等待下次按需检查。运行相位、未读信号和原生身份绑定继续独立更新。
- 切换页面、关闭标签、收起侧栏或改变拆分布局不停止会话；再次打开附着同一个 PTY，继续接收输出，不重新发送首条指令。
- 进程生命周期仍只用可确认的启动中、运行中、已停止、失败。在此之上可按 Agent 能力展示运行相位（回答中、空闲、等待权限、等待回答、后台任务、重连等；「有新回复」不作为相位，统一由未读表达），数据只来自该 CLI 已确认的结构化事件或原生会话元数据，不扫描终端 ANSI 猜测，也不注入 hooks。无可靠信号的 Agent 只保留进程四态；各 Agent 可取得的相位、等待原因与回复信号以能力矩阵为准，矩阵是本轮交付物，维护在 [会话信号能力矩阵](agent-session-signals.md)；矩阵未列为可靠的项整项隐藏。
- 等待原因：仅当上述事件能指明「等哪项权限／哪个问题」时，在会话条目副文案或悬停卡展示；无原因字段时不显示占位。点击原因可聚焦到终端对应输出（若有定位信息），否则仅展示文案。
- 已读／未读：使用单独的最近回复时间 `lastReplyAt`，只在能力矩阵确认的助手回复结构化事件（或原生会话元数据中的新回复）到达时更新；PTY 输出、CLI 重绘、用户输入及现有最近活动时间 `lastActiveAt` 均不计入。`lastReplyAt` 晚于本机按会话保存的已读水位即为未读；没有回复信号的 Agent 不显示未读。打开该会话面板或手动「标为已读」更新水位。不把「终端安静」当成回答完成。任务标签与 Tasks 卡片汇总时，关注优先级为失败 ＞ 未读 ＞ 运行中／启动中 ＞ 已停止（具体聚合规则见任务列表）。
- 会话悬停详情：活动会话条目悬停展示最近活动时间、工作目录／工作范围、进程状态，以及有信号时的运行相位与等待原因；不含用量／token（用量另立项）。无字段则省略该行，不填假数据。
- 本轮不做：运行时配置回显、用量信息、会话深链、归档历史阅读器；会话深链等后续单独开项。
- 标签前使用会话状态图标而非固定任务图标，无会话显示空心圆；多会话优先显示失败、未读、运行中、启动中，其次停止。Tasks 卡片和列表另以分组标记并列展示各状态会话数，不以标签的单状态汇总代替分组。
- 停止会话结束其进程树但保留记录。恢复对话与重启 Agent 均连接原生对话，不重发首条任务指令；重启会先停止旧进程，新建会话才创建新的对话。
- 归档会话先停止其 CLI 及子进程，再持久化归档时间。归档记录保留在 SQLite，不删除 CLI 原生历史、任务或仓库；不参与活动会话列表、自动附着和任务标签的会话状态统计，不能通过普通重启/恢复入口重新启动。归档写入失败时保留已停止的条目并显示操作错误，允许重试；会话分组内提供默认收起的“已归档 N”；没有记录时不显示。条目保留 Agent 图标、名称、工作范围及归档时间提示；点击恢复先返回活动列表并选择，随后按可见会话的自动恢复规则处理；解除归档本身不启动进程。恢复更新元数据时间，不制造活动时间；原生会话身份及配置保持不变。需先恢复已归档任务，才能恢复其会话。支持的原生会话仍可通过二次确认删除，不提供完整历史对话阅读器。
- 重命名通过确认弹窗填写名称（1–160 字符），明确提示会先停止会话以避免 CLI 并发写入覆盖名称。确认后修改精确对应的原生标题元数据，再同步 Navo；保留对话历史，不重新发送任务。原生记录变更、权限不足或写入失败时保留条目并显示错误，不仅改本地标题。修改完成后可手动恢复原对话。
- 删除通过二次确认明确说明永久删除 CLI 历史及 Navo 记录，默认焦点在取消。确认后停止进程，Grok 通过原生删除命令处理，Claude 清理精确会话日志、所属子记录与索引项；原生删除成功后才删除 Navo 记录。取消不做任何操作，失败保留已停止的 Navo 条目供重试，不删除任务、仓库、Worktree 或其他会话。路径替换、原生 ID 不匹配及未知来源必须拒绝操作。
- Claude/Grok 通过 `--resume <原生 ID>` 恢复；Codex 使用 `resume <原生 ID>`，Antigravity 使用 `--conversation <原生 ID>`。恢复保持工作目录和原生对话身份，不追加首条任务指令，不使用最近会话选择器。CLI 不支持恢复参数或原生历史缺失时显示失败，不退回新对话冒充恢复。
- Claude/Grok 创建时可指定会话 ID；Codex/Antigravity 新对话首条指令携带非敏感的唯一关联标识，结合实际工作目录从本机原生记录核对，唯一匹配才持久化原生 ID 并开放恢复和重启。原生记录延迟出现时后台继续核对，多候选、读取失败、格式不支持均不猜测。旧会话缺少可靠关联时不允许恢复或重启，可从新建会话入口另开对话；重启失败保留原对话身份供重试。
- 应用重启先恢复会话记录，原先运行中的会话标为停止，列表加载本身不启动进程。当前任务的会话面板真正可见、窗口处于前台、原生 ID 已绑定且没有阻断错误时自动恢复；隐藏标签、折叠面板、被终端或侧滑区域遮住的面板不触发。每个页面实例对同一会话只自动尝试一次；分屏请求共用队列，并发恢复已运行会话不重复启动。
- 用户手动停止、正常退出、启动/恢复失败后不自动重试；应用退出及窗口关闭保留待恢复标记，之后可见时按条件恢复。已归档任务禁止自动和手动恢复；已归档会话必须先解除归档。Worktree 初始化未完成或目录不可用时不启动，失败保留手动恢复入口。历史记录缺少停止原因时，未归档、无错误且可恢复的停止会话按待恢复处理。窗口销毁及退出应用会清理所属进程。
- 删除任务先停止任务会话与终端，再执行原有安全删除流程；清理失败保留任务及已停止的 Agent 记录。归档任务先停止其 Agent 和初始化命令，保留会话历史；可选择清理 Worktree／本地分支，选择清理时同时关闭本任务终端，风险和重试规则见 Tasks 页面。未选择清理时保留普通终端及所有目录。归档单个会话只停止对应进程，不清理目录；恢复任务不会自动启动 Agent 或重建已删除目录。
- 不将任务正文、启动 prompt、终端输出或认证内容写入诊断日志。

## 5. 验收

- 单仓库、多仓库、无仓库的默认目录与显式目录选择正确；缺失目录不会启动到其他位置。
- 任务创建重试只启动一个初始会话，启动失败不影响任务保存。
- 隐藏/关闭/重新打开页面不重复创建进程，多个任务和多个会话相互隔离。
- 终端新增、选择、关闭与上下文同步，清零隐藏分组及数量角标；关闭会结束运行中的命令。
- 中英文界面文案完整，模型/模式/思考等级保持原始名称；宽标签、窄侧栏与拆分页不溢出。
- 真实名称读取严格对应会话 ID，进入详情、新建和重命名后按需同步，后台状态更新不反复读取已有标题；隐藏标签不触发标题检查，未获取时不显示 Agent 加编号或猜测标题。归档操作不误触选择、不影响其他会话，重启应用后仍归档，延迟的退出事件不能将归档会话恢复为活动状态。
- 两个加号入口使用相同的 Agent 菜单及默认值规则；关闭面板后进程保持运行，点击上下文可恢复原面板。重命名不丢失原生历史，删除取消无副作用，原生删除失败不会把 Navo 记录当作成功移除。
- 仅通过模拟 CLI/隔离终端做自动化验证，不在测试中使用真实账号发起模型调用。
- CHANGES 高亮与当前工作区及面板显隐一致；Notes 与分支栏互斥，笔记保存后重载恢复、取消不写入、删除需确认，失败不丢草稿，宽窄切换及关闭上层确认框不误关下层面板。
